Using templates                      

The template feature allows you to immediately load distributor, operator, or product information when creating new contracts.  This is particularly useful when dealing with similar products across a wide range of contracts as it will eliminate the need to search for and select products each time.  When creating the template, use the "Contract Title" field to describe the contents of the template as a reminder (for example, "All 48 oz. Red Wine Products").  Additionally, templates can save time if you have several contracts that include a large set of the same distributors (for example, "All Southeast Region Distributors").
