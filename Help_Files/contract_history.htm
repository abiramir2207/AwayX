Contract history                                   

When:

Provides a time stamp for each change made and saved

By Who:

 Record of the user that saved the changes

What was changed:

 Description of the data field, selection, status, or rate that was changed.
From: The state of the altered area prior to the change.
To: The new information that was saved.
Delta: The difference between the prior and altered states.  This field is color-coded for quick-reference with red fields indicating removal, green signifying additions, and blue representing changes.
Message Traffic: Clicking on "Message  Traffic" at the bottom of the page will open an expanded view of a log for all email and fax message traffic associated.
