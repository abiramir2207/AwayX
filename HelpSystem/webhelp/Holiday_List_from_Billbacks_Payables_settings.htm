Holiday List from Billbacks Payables settings

Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings > Payables > holiday list

URL Properties: billbacks/Check_Book/Bank_Tran/General_Ledger_Account/Create_Holidays.cfm

Use the Billback holiday management page to view, edit and create holidays in the system that correspond to your organization's holidays.

 

Columns/Controls on this page:

Last Updated by: The user id and date/time stamp shows who last updated this page.

Stored Records: Description, Date, Status

Edit Record - Date, Description, Availability

[Create New Entry] link

[save data] link

 

How to use this page

The Stored Records page displays the existing records with their Description, Date and Status (Active/Inactive).  

Click a description to display the record in the Edit Records area.  In the Edit Records area, you can change the Date, Description and Status, and you can change the Active/Inactive settings.

If a priority is inactive, you can click its link in the Stored Records area to display it in the Edit Record area, and a [delete data] link displays next to the [save data] link.
