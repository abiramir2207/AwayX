Columns on this page:

Position (search position)

Operators (search operators)    

How to use this page

Use the Operators - position assign page to search for positions and then to search for and assign operators to positions.

Click the [search position] link to display the user position search page.  This page displays a listing of positions based on your search criteria; the total number of positions that match the criteria you enter displays.  

Select a position to which you want to assign an operator, and click the [import selected position] link.  

The Position - Assign page redisplays showing the position you selected, with an additional link in the right-most Market column called [Operators in this position].  Click this link to view the operators associated with this position.  You can sort by any of the columns on the operators in this position page.  Columns include Operator Name, Location Type, City, State, # of Locations, Doing Business As, and Position.  You can sort by any column by clicking its column link at the top (for example, clicking the State link sorts by state and presents you with the triangle with which to reverse the sort order).

Click the [search operators] link to display the search operators page.  This page displays a listing of operators  based on your search criteria; the total number of operators  that match the criteria you entered displays.  

From the listing of operators, select and import the operator record.

The Position - Assign page displays, and you can assign the operator to the position by clicking the [assign] link.
