Product Growth Entry page

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Programs (click a program link) > click growth

Product Growth is where you set up the particulars of the program's product volume incentives.  You can use the product growth fields to configure simple or sophisticated growth relationships, using historical percent of volume for comparison, or you can establish stairways and discounts based on growth of a different product, and more.

Component Name - Enter a name for this growth component.

Description - Enter a meaningful description of what this growth component is intended to do.

Payment Cycle - Select the payment cycle (frequency) for this growth component.

Component Type - Use the radio buttons to select what type of growth component this is.  Each type of growth component is described more fully below.

Normal growth component - As the screentip states, normal growth components establish tiers of volume for one set of items that need to be purchased.  Once enough volume has been purchased to reach a tier, items are discounted at the tier's rate.

Stairway to Heaven - A stairway component has product targets, and they must be achieved in order. For example, in stairway growth, the program might award a discount on 'product A' provided 100 cases of 'product B' are sold first.

X of Y - This type of growth component allows you to tie the discount on one product based on the percentage of growth of another product.

 

Normal growth component:

If you select the normal growth component and click [continue], the next growth page displays: Product Growth Component Creation, subtitled Define Your Component.  This page contains two sections: Component Information and Component Tiers.

Component Name and Component Description display from the previous page.

Rate: Select the radio button for either Single or Multi Rate.

For normal growth components without separate volume pools you can choose to have the component calculated on a multi rate basis.

Multi-rate Growth pays more for each volume tier attained (for example, Tier one may require selling 10-20 cases of product and award a 10% discount; Tier two may require selling 21-40 cases and award a 15% discount, and so on).

Single rate means the award associated with the tier attained will be awarded for that tier as well as for the tiers below it (as contrasted with multi-rate, where the award for a lower tier is the same regardless of how many additional tiers are attained).  For single rate, once you attain a tier, the rate for that tier is awarded to all volume.

Separate Volume Pool checkbox: If you choose multi rate, you cannot select this checkbox.  Volume pool separation allows you to establish tiers based on one set of items (for example, 'product A'), while awarding discounts to a different set of items (for example, 'product B').

Component Unit of Measure - select the unit of measure (case, pounds) used for this growth component using the drop-down.  If you select percent from the drop-down, you are selecting a percentage of volume as the unit of measure.  If you select percent, an additional related field displays, so you can select the period to use for the volume comparison.

(Percent UOM only) Volume Comparison Period - Select a radio button for either Same period, prior year or Days before program start date (if you select the latter, fill in the number of days).

Same Period, Prior Year: If you select same period, prior year, then the amount of time is the span of the program you are currently creating, but one year ago. So if the program runs from September 1, 2005 until September 30, 2005 then the comparison period would be from September 1, 2004 until September 30, 2004.

Days Before Program Start Date: This creates a comparison period immediately prior to the start date of the program. The length of the comparison period is the number of days you enter.

How many tiers - Enter the number of tiers needed to establish this growth component.  As soon as you enter the number of tiers, the  Define Your Tiers/Component Tiers section expands so that you can list each tier.

For each Tier, enter the Range Start, Range End and Bonus amount.  Enter an asterisk for a tier component that has no upper limit.

Notes: If you selected percent as the UOM, the percentage you enter in the tier(s) is the percent of purchases the client made in the comparison period.  Also note that if you want to create a tier that requires a customer to buy more of your product than they did in the comparison period, your tiers must start at 100%.

Click [continue] when you are finished entering your tier ranges and bonuses.

The next growth component page displays: Select Growth Products.

Select Growth Products - Note the [component information] link (this returns you to the Define your component information) and [main growth page] link (this returns you to the Product Growth Entry page that lists all growth components on this program).

Use the [select products] link or the [add all products] link to select the products for this growth component.

If you use the [select products] link, the Product Search page displays.  Use the drop-downs to restrict your search, and use the [reset] link to change your selections.  Click the [get products by program] link to display the program search page.

 

X of Y growth component:

If you select x of y, the Select Growth Targets page displays.

Enter the target name, the volume target and unit of measure.  Enter the bonus to be awarded if the volume target is attained.

Click the [Select Groups] link to select the product groups to include in this x of y growth component.

Select the group level, click the [get groups] link, and select the individual groups to import (or select all groups using the checkbox in the header row).  Click the [import groups] link, and the select growth targets page displays showing your selections.

Click the [save and add target] link to save these selections to add another target for the x of y growth component, or click the [save and continue] link if you are finished selecting growth targets.  

The Select Growth Products page displays, with links to [add target] or return to the [main growth page].

Click the [Select Groups] link to add products for this x of y growth component, and when you select/import, the tier, rate and product pricing tier fields display.  Note the many links on this page that permit you to do whatever is needed to build the growth component: [add target], [main growth page], [apply rate] (to all products at a tier), [save], [select groups/select products], [apply a UOM to all products], and so on.

In the Product Pricing section, you can individually select or delete products/ groups, and enter tiers for the x of y growth for each.

When you click the [save] link, the Growth Components page displays and you can see your new entry.  To review your entry (and to edit it), click the [edit] link next to your entry in the Growth Components page, and the Growth Targets page displays for the x of y components.

 

Stairway growth component

If you select x of y, the Select Growth Targets page displays.

Enter the target name, the volume target and unit of measure.  Enter the bonus to be awarded if the volume target is attained.

Click the [Select Groups] link to select the product groups to include in this stairway growth component.

Select the group level, click the [get groups] link, and select the individual groups to import (or select all groups using the checkbox in the header row).  Click the [import groups] link, and the select growth targets page displays showing your selections.

Use the [add target] link to add additional targes or click the [return to the main growth] page link.

 

When you have finished with growth components, the next program page to enter is the date exclusions page, if applicable.
