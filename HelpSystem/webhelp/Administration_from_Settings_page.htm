Administration from Settings page

 Blacksmith Applications, www.blacksmithapps.com

 

administrator - This link lets you select who should be an administrator-level user, and who the contact person is for the administrator(s).

fiscal year - Follow the steps as indicated to set up your fiscal year information:

How many Accounting periods does your fiscal year have?

Please define the first day of the first period

Please define the length of each period (in days)

logoff time out - Per the screen text, for security considerations, if there is no browser activity after the period of time you select, the user session will expire and the user will be forced to login before using the application.  You can elect to not have user sessions expire (this is not recommended) or you can enter a number of hours after which the session should expire if there has been no browser activity.

application settings -

Program Interface Buffer - enter the number of days to allow for the program interface buffer.

No. of days to allow a profile to take action - enter the # of days to allow before a profile can take effect.

Report Scheduled for every - click this to display the RFA report scheduling screen.

The report name displays; select the start date, start time and report interval.  Then, select the email addresses to whom the report should be sent.  Finally, select the [schedule RFA Report] link.

Do not email password to the new users - Depending on your organization's policies, you may choose to disable the facility by which the system emails a system-generated password to new users when they are created.

Do not email Self-Updated password to the users - Select this checkbox if you do not want the system to email the user with their changed password.

Do not email Administrator-Updated password to the users - Select this checkbox if you do not want the system to email the user the changed password when you (as administrator) change their password.

No. of days for traffic Info - Enter the number of days to use as the default for the system to display traffic information for (traffic information displays in Settings, Users, Traffic Info).  Whatever number you enter here is used by the system as the default number of days back to which to display user traffic (access) information.  You can change the default date range on the traffic info page.

SAP interface buffer to send programs - Enter the number of days to allow for the ERP interface buffer.

No. of days for changing user password (0 (Zero) days means that the users will not be required to change their password) - Depending on your organization's policies, you may want to force each user to change passwords periodically for security purposes.  If you enter 30 in this field, users will be prompted to change passwords every 30 days.

Printer Name:

[Generate Status Report] - Click this to generate a report showing the status of all programs, sorted by region and market.  Information includes Program Number, Program Title, Start Date, End Date, Status and Status Changed Date.

[Generate RFA Report] - Click this to generate a report listing all RFA programs.  Information includes Program Number, Program Title, Program Volume (Cases), Start Date, End Date, Days In RFA Status, the position Currently responsible for approval, GDW Level 4, and the Responsible profile(s).  The responsible profile column lists the user profiles who have approval rights, in  hierarchical order if there are multiples.

deleted programs - select this to display a listing of all deleted programs.  Click the undelete checkmark to undelete a program.

reports - this displays the Contract Management Performance Metrics Report.

data integration viewer - Click a calendar date that is colored red on the calendar to display the details of the data transfer.  If records were rejected, you can click the link to view them.  If records were transferred, you can click the magnifying glass to see the details.  Read the description of the data integration viewer that displays when you initially select it for details.
