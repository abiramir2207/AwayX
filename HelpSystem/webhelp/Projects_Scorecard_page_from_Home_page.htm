Where can I find this in FORGESM?

Home > Projects

From the Projects Scorecard, you can display a listing of the projects of any given priority (such as Medium, or High, for example) by clicking in the priority row. The Project Management page displays in summary view, showing a row for each project record that exists with that priority.  

The summary view is also used by the project search.  To see the criteria used to select the projects shown, click the [Show Criteria Used] link (if displayed from the project scorecard, the Priority criterium will reflect your selection).  Click the [Hide Criteria Used] link to collapse the project criteria.

Click the [detailed view] link to expand the project summary records; click the [summary view] to collapse the detailed view back to a single line.  The detailed view gives you an overview of the project details and allows you to display the program(s) using the program link (the program displays in read-only mode).  You can also issue email by clicking the small yellow envelope (next to Sponsor and Owner Positions, for example).

To see the complete project records, click the project title from either the detailed or summary view.  The project page displays in read-only mode.

Use the links at the bottom of the project listing to work with projects: [ create a new project ]  [ search projects ]  [ export projects to XL ].
