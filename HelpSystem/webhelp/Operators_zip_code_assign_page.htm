Settings Control Panel > Geography > Operators > postal codes tab

URL Properties: settings/Operator_Tree/index.cfm?mode=1

Columns on this page:

Market (search market)

Postal Code (search postal codes)    

How to use this page

Use the Operators - postal code assign page to search for and assign markets with postal codes.  By assigning the markets with postal codes, you are providing the information the system needs for the position tree that displays when you click user positions.

This assignment also allows a user (with adequate permissions) to see the programs of an operator who is in their market.

Click the [search market] link to display the search market page.  This page displays a listing of markets based on your search criteria; the total number of markets that match the criteria you entered displays.  

Select a market or markets to which you want to assign a postal code(s), and click the [Import Selected Records] link.  

The Postal Code Assign page redisplays showing the market(s) you selected, with an additional link in the right-most Market column called [postal codes in this market].  Click this link next to a market to view the postal codes associated with this market.  

Note that you can sort by postal codes, and that the columns included for postal codes include: Postal Code,  City, County, State, Area Code, Time Zone, and Market.  You can sort by any column by clicking its column link at the top (for example, clicking the [Time Zone] link sorts by time zone and presents you with the triangle with which to reverse the sort order).

Click the [search postal code] link to display the search postal code page.  This page displays a listing of postal codes based on your search criteria; the total number of postal codes that match the criteria you entered displays.  

Note that you can click the postal code in the listing that is returned, and a map displays with the postal code location indicated.

From the listing of postal codes, select and import the postal code records.

The Postal Code Assign page displays, and you can assign the postal code to the market by clicking the [assign] link.
