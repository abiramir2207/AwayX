Program-related User Profile Approval Rights

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings Control Panel > Users > user profiles > Programs

URL Properties: settings/Access_Rights/index.cfm?PageTitle=Users: user profiles

 

Program Approvals

Program - View & Create - Indicate whether the user profile should have permissions for both viewing and creating programs.

Program - View Only - Indicate whether the user profile should have view-only access to programs.

Program - None - Indicate whether the user profile should have no access at all to programs.

View Margins - Indicate whether the user profile should be able to view margin information.

Approval Rights: Select the checkbox for the user profile if this profile will have any program approval rights at all.  If this user profile should not have any program approval rights whatsoever, leave this checkbox unselected.

Cancel Program - Indicate whether the user profile should have permission to cancel programs.

Approve All Products Program- Select this checkbox if this profile should have rights to approve programs that are set up to have all products.   

Approve Group Deals – Select this checkbox if this profile should have rights to approve group deals (i.e., programs that have a set or group of products, as opposed to individual products, as set up in Users, approval groups and Approval Methods group product assignments).

Mass Approve RFA Programs – Select this checkbox if this profile should have rights to approve multiple RFA programs at one time rather than approving them per program.

Approve Growth Programs – Select this checkbox if this profile should have rights to approve growth programs (i.e., programs that use growth as the discount type).

Approve Advanced Funds- Select this checkbox if this profile should have rights to approve advanced funds for programs.

Approve Equipment/Dispenser Placement - Select this checkbox if this profile should have rights to approve equipment/dispenser placement for programs.

Program Approval Methods

Approval Methods – There are 5 basic methods of approval permissions in FORGESM.  These additional types of permissions give you complete control over approval rights.  

Approval Method Values – dollar per pound margin - For each group you have set up within Users, Approval Groups, you can enter a value per profile for which each profile should have approval rights.  For example, say you have a user profile called Regional Manager, and you have groups set up for products (ABC, and XYZ).  If you enter 12 under the Regional Manager profile next to product group ABC, you are indicating that this user profile will have approval rights for programs using product group ABC for which the dollar per pound margin is at least 12 percent.

(To see the group's product assignment details, simply click the group link.)

For each applicable profile, enter the value for dollars per pound margin of profit that must be earned before this user profile will be permitted to approve.

Approval Method Values – percentage margin click – For each group you have set up within Users, Approval Groups, you can enter a percentage that must be earned, per profile, for which each profile should have approval rights.

Approval Method Values – total program percent margin – This applies to the entire program rather than to the group levels.  Use this to enter a percent margin that the total program has to earn before this user profile can approve.  This allows you to give approval rights for a program that may contain some products that are a loss, but are offset by other products to yield an overall margin of the percent you enter.

Approval Method Values – spending cap – For each group you have set up within Users, Approval Groups, you can enter a spending cap that cannot be exceeded on that program.  If the cap is exceeded, the selected user profile will not be able to approve it.

When you use the spending cap, you can use the additional fields (Lump Sum, Flat Sum, Inactive Lump Sum Approval, Growth Lump Sum Approval) to establish a pricing floor mechanism.  The amount you enter in these fields is used to prevent a price below the amount being offered for the product, and/or to specify how far below the floor it should be allowed to go.  If the price goes below the amount you enter here, special approval would be required.

Approval Method Values – layered  – (note that you may not see all of the fields described below, and that the verbiage may be different).  Layered approval means that the approval field values below are considered sequentially for a profile, from Level to Min Approvable Volume, in determining whether the profile can approve.

Level - Access/Approve (the verbiage you see may differ) - For each profile, you can click the [view] link and see the products that this profile can approve, and the variance from the target margin within which they can approve.

Approve Lumpsum - Indicate with a checkmark which profiles can approve lumpsum spending.

Base View - Indicate with a checkmark which profiles should be able to see the margin targets page within Programs.

View Operating Income - Indicate with a checkmark which profiles should be able to see operating income information on the program margin target page.

View Cost - Indicate with a checkmark which profiles should be able to view program cost information on the program margin target page.

View Target Margins - Indicate with a checkmark which profiles should be able to see program target margin information.

Margin Target Variation - Enter the margin target variation permitted for this profile.  This profile will be permitted to vary from the margin target by the amount you enter here.

Min Operating Margin% - Enter the minimum operating margin allowed for this profile; this profile will not be permitted to approve less than this margin %.

Max Approvable Volume - Enter the maximum volume that this profile can approve, and select the unit of measure.  Volumes greater than this cannot be approved by this profile.

Min Approvable Volume - Enter the minimum volume that can be approved by this profile, and select the unit of measure.  Volume below this cannot be approved by this profile.

More Program Approvals

Read Only Catalog Access - Indicate whether the user profile should have access to the read-only program catalog.  

Approve Duplicate Programs - Indicate whether the user profile should have permission to approve duplicate programs.  Your program template may or may not include parameters that define what constitutes a duplicate program.

Reassign Programs - Indicate whether the user profile should be able to reassign programs.

Reimbursement/Spend Update - Indicate whether the user profile should be able to change reimbursement or spending amounts for a program.

Restrict Program Access to Created by - Indicate whether this user profile should have access to only those programs they created.

Executive Agreement - Indicate whether a user profile that doesn't have program approval rights should have executive agreement rights, so that they can indicate they are in agreement with the program.  This is a means of letting someone without approval rights to indicate they support the program, and to move the program to a higher level of approval.

RFA options: Select the RFA (Request for Approval) option appropriate for each profile: these settings are used to direct the workflow.

RFA scorecard - Agreed - Indicate whether the user profile should be able to view all RFA's that have been agreed.

RFA scorecard - Executive agreed - Indicate whether the user profile should be able to view RFA's that have been executive-agreed (seen by executive level and above) in the program scorecard count.

RFA scorecard - Display all - Indicate whether the user profile should see all RFA's in the program scorecard count.

Approve Roll Over Programs - Select this if the user profile should be notified to approve manually renewed (not auto-renewed) programs. A roll-over program is a program that uses all of the same data as the existing program, except with a new set of start and end dates.  All of the program's details are the same as the program being rolled over.

Display broker list - Select this if the user profile should see the brokers that are associated with a distributor.

Approval is based on - Use this to select what the approval permission for this user profile is based on.  For example you might want to condition the approval permissions for a user profile to dollars per pound, or to a total program margin.

Fund Setting Access - Select this checkbox if the user profile should be able to access and modify Fund settings (Fiscal Year AR, in Settings, Payables).
