Where can I find this in FORGESM?

Home > Create program > Select Program Type  > Basic Program Info > (continue)

Programs Scorecard > (click program link) > (customers link)

When you click the [continue] link from the Basic Program Information page (the first page you enter when creating a program), the Select Program Customers page displays, and the left pane reflects that you have gone from the basic info page to the customers page: in the left pane, customers is now in red, bold text.

The Customers search by groups fields let you search for all in each category, or search for selected members of each category.  (click to see an image of customers search by groups).

In addition to using drop-downs to select from the fields above, you can enter and search by Name, and by Sold To (and you can add Sold To information by clicking the [create list] link).  To enter Sold To information, you need the Sold To # for the customer.  When you enter the sold to number(s) and click [Submit], the system determines whether the sold to entry (or entries) is valid.  If your entry is valid, click [continue] and the system searches for customers based on the sold to.

Select the search field on which to sort your search results using the Sort By drop-down, and select ascending or descending order using the Order drop-down.

To clear any search criteria, click the [reset] link in the lower right.

To execute your search, click the [search customers] link.

To simply add all customers, click the [add all customers] link.  

Click the [get customers by program] link to display a program-based search page.  The program-based search page is the same page that displays from the program scorecard.

When you have returned a list of customers, the assign weights (of expected product volume purchased) fields display followed by the list of customers.  Note that it may take a minute to refresh the page if you have many customers and/or if you choose add all customers.

You can enter weights individually, or you can enter a percent to apply to all customers, or you can have the pre-determined percentage applied to all customers.

When you have successfully selected program customers and saved, the next program page to enter is the Select Program Territory page.
