Position Search page from Operators

Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings Control Panel > Geography > Operators > position tab > search position

URL Properties: search_screens/Position_Search.cfm

Select any combination of columns on which to search or just click the [search position] link to display all entries.

The Divisions, Regions, Territory and Position Under selections display using drop-down arrows, and you can enter the Label directly.

Click the "currently selected positions" triangle to toggle the view to currently selected positions.

When you click the position link, the results display by Label, Zone, Region and Market.  You can sort by any of these columns by clicking the column header; click the triangle to reverse the sort order of a column that is selected for sorting.

Click the radio button next to the position row that you want to include, and then click the [import selected record] link.

The Position Assign page redisplays showing the position you selected, with an additional link in the right-most Position column called [Operators in this position].  Click this link to view the operators associated with this position.  You can sort by any of the columns on the operators in this position page.  Columns include Operator Name, Location Type, City, State, # of Locations, Doing Business As, and Position.  You can sort by any column by clicking its column link at the top (for example, clicking the [State] link sorts by state and presents you with the triangle with which to reverse the sort order).

Click the scissors icon to the left of a row to mark it for removal from the selected list. When you click the scissors icon, the row is shown with a line through it to indicate it has been marked for removal, and the scissors icon changes to an "undo" arrow.  Click the undo icon to return the row to its selected status.

To actually assign a position to an operator, click the [assign] link and a message displays indicating the position and operator that are now assigned.
