Product Lump Sum Component Creation page

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Programs (click a program link) > click lump sum

After you save the product rebate entry program page, the Product Lump Sum Component page displays.  There are two steps in lump sum component creation: Add a Lump Sum component, and, optionally, Add products to the Lump Sum.

Use this page to add a lump sum component.  The lump sum components that display in the drop-down come from the entries in your settings, programs, lump sum components.

In the Add a Lump Sum component section, select and enter the following:

Name - Select the lump sum component using the drop-down.

Amount - Enter the lump sum amount to pay.

Volume - Enter the amount (volume) that must be sold to qualify for the lump sum. Volume is used to help calculate the margin for various products. Enter the total volume for all products whose margins should be adjusted to take this lump sum component into consideration.

Payment Cycle - Select the payment cycle for this program's lump sum using the drop-down (monthly, quarterly, etc.)

Description - Enter a meaningful description for this lump sum component.

Click the [save component] link to save your entries, or click the [reset fields] link to clear any entries you've made in this page and start again.

When you click the [save] link, the Select Lumpsum Components page displays, where you can select products for the Lump Sum if appropriate.  If this is an existing Lump Sum entry, click the [product] link to display the Select Lumpsum Products page.  From the products page, you can right-click within any row and display the Program Group Items or Current Group Items that make up the selected group row.

Click either the [select groups] or the [add all products] link to choose lumpsum-eligible products.  Note that if you select the [add all products] link, you will see a single entry that says "all products" after the system adds all products.

If you click the [select groups] link, the Select Product Groups displays.  

Select a group level using the drop-down, and then click the [get groups] link.

Select the checkboxes of the product groups you want to retrieve for this lump sum component, and click the [import groups] link.  The products you select should correlate to the product volume you entered in Volume, above.  

The Select Lumpsum Products page displays showing the product groups you selected.

You can click the [create new] link to return to the product lumpsum component creation page, or click the [delete selected products] to remove products from this component, or if you are finished with lumpsum component creation, click the [continue] link to continue to the next program page, Product Growth Entry.
