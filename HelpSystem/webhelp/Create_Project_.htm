Create Project

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Projects > create new project

 

Project name - Enter a descriptive name for this project (you can use up to 100 characters).

Priority - Select the priority of this project, using the drop-down.

Status - Select the status of this project, using the drop-down (initially, a project status might be Open).

Phase - Select the phase to which this project belongs.  Selecting a phase lets you associate the project with a marketing phase of the initiative (for example, RFP, Launch, Presentation, Negotiation).

Period - Select the start and end dates for the project using the calendar (you can also enter the dates directly).

Owner Position - Select the Owner Position(s) for this  project.  This allows you to associate the project with a position, so that any user(s) assigned to the position(s) will see this project.  Click the [pick from list] link to display the standard user position search page.  You can import more than one user position and select multiple project owners (per the message on the page, "Hold ctrl and click to select multiple items".

Product Item Groups - Click the [pick from list] link to display a standard selection list of Product Item Groups displayed by Legacy id and Product Item Groups.  Select the checkbox of the Product Item Groups to use in this project, and/or use the links at the bottom of the page to return the products you want to be in this project: [ import selected Product Item Groups ] [ import all returned Product Item Groups ] [ remove all selected Product Item Groups ].

Territory - Click the [pick from list] link to display a standard search page for brokers by territory.  Select the brokers to associate with this project, and use the links at the bottom of the page to return the brokers you want to be in this project: [ import selected brokers ] [ import all returned brokers ] [ remove all selected brokers ].

Customers (Distributors) - Click the [pick from list] link to display a standard search page for Customers.  Select the customer to associate with this project, and use the link at the bottom of the page to return the customer you want to be in this project.

Operators - Click the [pick from list] link to display a standard search page for operators.  Select the operators to associate with this project, and use the links at the bottom of the page to return the operators you want to be in this project: [ import selected operators ] [ import all returned operators ] [ remove all selected operators ].

Value Lbs - Enter the value in pounds for this project.

Value $ - Enter the value in dollars of this project.

Resources $ - Enter the cost in resources required for this project.

Sponsor - Select the sponsor of this project.

Functional Area Responsible - Select the functional area responsible for this project (for example, if this project is driven by marketing, select Marketing).

CER/Acct Number - Enter the account number that should be charged for this project.

Support - Enter the name of the person or department that supports this project (this may or may not be related to the Functional Area Responsible).

Budget $ - Enter the amount that is budgeted for this project.

Actual $ - Enter the actual cost of this project once it is known.

Programs - Click the [pick from list] link to display a standard search page for Programs.  Select a program or programs that will be associated with this project, and use the links at the bottom to return the program(s) to the project.  The selected program(s) initially display next to the Recently Selected programs.  Once you save (by clicking [save data], the programs move to Previously Saved.

Previously Saved - Selected and saved with the project.  You can remove a previously saved selection by deselecting the checkbox.

Recently Selected - Selected but not saved with the project.  Note that you can deselect a selection prior to saving the project.

Documents- Attaching documents to a project works like selecting programs as described above.  Click the [attach from list] link to display a standard search page for Documents.  Select a Document or Documents that will be associated with this project, and use the [attach selected documents] link at the bottom to return the Document(s) to the project.  The selected Documents initially display next to the Recently Selected Documents.  Once you save (by clicking [save data], the Documents move to Previously Saved.

Previously Saved - Selected and saved with the project.

Recently Selected - Selected but not saved with the project.

Notes: Next Step/Update - Enter any notes that will help manage this project, and/or enter information about the next step or stage of the project.  This section can provide a history of the project over the course of the project.

Create/Edit Project links - [ save data ]  [ search projects ]  [ back to search results ]  [ copy this project ]

[ save data ] - Save your entries: You must click [save data] in order to save your project.  If you do not click [save data], your entries will be lost.  Once you click [save data], the project summary page displays in read-only mode.  Click Edit to return to edit mode, or click the [ search projects ]  or  [ back to search results ] links.

[ search projects ] - Use this to display the search projects page, with its links for [ search projects ]  [ reset settings ] [ create new project ].  Note the link on the search project page that says:  [Go here to manage the status, priorities, phases, sponsors and functional area lists]. Clicking this link brings you to the Control Settings page, where you can manage the various project-related items provided you have adequate permissions.

[back to search results ] - Returns you to a previous search result page if applicable.

[copy this project] - Clicking this link creates a copy of this project (the name is also copied, but is prefaced with "Copy of").  The copied project displays in read-only mode, and you can click edit to make changes to the project and save it.
