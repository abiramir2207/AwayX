Product Rebate Entry page

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Programs (click a program link) > click rebate

The Product Rebate Entry page displays after the select program territory page.

The rebate Component Names come from the entries in settings, programs, rebate components.  

Select the products for which this rebate component applies, using the [add product groups] link or the [add all products] link.

If you choose the [add product groups] link, the product group select page displays.  Any product groups you have created are selectable using the drop-down arrow.

Select a group level and click the [get groups] link to display a listing of all groups included in the level you selected.  To see the products that comprise the group, click the group name and all of the product items in the group display.

Use the checkboxes to select the group(s) to include for this rebate and click the [Import Groups] link.  The product rebate entry page redisplays showing the group(s) you selected.

Or, you can choose the [add all products] link (rather than the [add product groups] link).  Use the checkbox in the row header to select all groups/products for the rebate component, or select groups/products individually by selecting the checkbox next to each.

Select a component for this program's rebate, enter a default rate for this component and select the unit of measure for the rate.  

Indicate using the radio buttons whether this rebate component should be paid to a Distributor or Operator.

When you click the [include this component] link, the product/group listing reflects the addition of this rebate component.

Use the Multi Assignment Tool section if you have already created a component and want to change the rate for a number of products in the component. Click the checkbox to the left to select the products, enter the rate, select the UOM and click on [apply this rate/uom] to make the change to all selected products.

When you have the product(s), rebate component and rates entered, with the product checkbox(es) selected, click the [save] link.  

The next program page, Product Lump Sum Component Creation, displays.
