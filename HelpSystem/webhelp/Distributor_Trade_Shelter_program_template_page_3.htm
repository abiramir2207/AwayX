Duplicate Program Definition, if applicable
 program template page three

 

This template page displays if you opted to check for program duplicates at the bottom of the basic info page.  Use the fields on this page to define what should constitute a program duplicate.

Remember that you can use this in conjunction with the Check for Duplicates warning, so that the user can find out which other programs use the same distributor and perhaps other parameters, yet be permitted to continue.

Use of all but the Dates section is optional; using additional sections allows you to more closely control what should constitute a duplicate program.

 

Fields on this window

Area

Fields

Description

Dates

Exact Dates

 

Overlapping Dates

In order to check for duplicate programs, dates must be used: therefore, Dates is the one required section in the duplicates page.

Select Exact Dates if you want the system to find a duplicate only if it finds a program with the exact same dates as the program created with this template.

Select Overlapping Dates if you want the system to find a duplicate program if it finds another program with that has dates overlapping with the program created with this template.

Distributors

Exact Distributor List

 

At Least One Distributor Matches

Select the Distributor checkbox if you want to use distributors as part of the duplicate program check.

Select Exact Distributor List if you want the system to find a duplicate only if it finds a program with the exact same distributor list as the program created with this template.

Select At Least One Distributor Matches if you want the system to find a duplicate program if it finds another program with that has at least one distributor in common with the program created with this template.

Operators

Exact Operator

 

At Least One Operator Matches

Select the Operator checkbox if you want to use operators as part of the duplicate program check.

Select Exact Operator List if you want the system to find a duplicate only if it finds a program with the exact same operator list as the program created with this template.

Select At Least One Operator Matches if you want the system to find a duplicate program if it finds another program with that has at least one operator in common with the program created with this template.

Products

Exact Product List

 

At Least One Product Matches
 

Select the Products checkbox if you want to use products as part of the duplicate program check.

If you select Products, the Discount Type  section is automatically selected; if you do not select Products, you cannot select Discount Type.

Select Exact Products List if you want the system to find a duplicate only if it finds a program with the exact same product list as the program created with this template.

Select At Least One Product Matches if you want the system to find a duplicate program if it finds another program with that has at least one product in common with the program created with this template.

Discount Type

Same Type

Provided you selected the Products checkbox, the system will look for the same Discount Type when looking for duplicates.

Rate

Same Rate

As with Discount Type, Rate is only selectable if you selected Products.  The system looks for the same rate when looking for duplicates.
