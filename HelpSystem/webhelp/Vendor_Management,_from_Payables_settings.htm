Vendor Management

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings > Payables >  vendor mgmt

URL Properties:  GL_Code/Vendor_management/vendor_Form.cfm

The Vendor Management page is where you can search, view, edit (update, delete) and create vendor detail records.  Often the vendor is the distributor.

Search section

Use the top of this page to enter search parameters for the vendor you want to search on.

You can enter the Vendor ID, and/or Sold To and/or End User ID, and/or you can use the select links to find the Customer Name and End User Name to search on.

The Customer Name is the party to whom the distributor distributes, such as a convenience chain, and the End User Name is the party who ultimately receives the product (for example, a franchisee owner, restaurant or school).

Use the [reset] link to reset the search fields, and click the [search vendor] link to execute the search.

Click the [create new entry] link to enter a new vendor detail on the Create Vendor Detail page.  The system validates the Sold To entry to the Customer Master in the database.  The system also checks to see that the entries for Sold To and Customer Number and End User ID and End User Name match appropriately.

Results Section

In the search results section of this page, you can sort by any column title by clicking the column header; to reverse the sort order of a sort column, click it again.

You can click the individual vendor links to display the Update/Delete Vendor Detail page: use the Delete button to delete the vendor, or make changes to the vendor detail and save them using the Save button.  

Sold To, Customer Name, End User ID, and End User Name have some validations, in the sense that the system will check that the Sold To matches the corresponding entry in the database, and that the End User entries (ID and Name) match.
