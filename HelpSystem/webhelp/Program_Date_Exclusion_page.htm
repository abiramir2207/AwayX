Program Date Exclusion page

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Programs (click a program link) > click date exclusion

If applicable, use the date exclusion page to identify date spans when this program should not be available for use.

Enter the date span during which this program is not enforceable, or select the dates using the calendar icons.

When you save the date exclusion page, the documents page displays.
