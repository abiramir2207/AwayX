Reports Central gives you a page from which you can access all FORGESM reports by functional area. Click to see a sample image of the Reports Central page.

 

Programs/Invoice

With the exception of the Program Revision Report, the Programs/Invoice reports are presented as tabs on a single Report Writer page.  

 

Program Summary -

Select the criteria to include for this report, and then click the [Save As Report Schedule] link or click the [show report] link at the bottom of the page.  The criteria fields for your implementation may differ from those described below.

Status - You can leave the default of "All" or select a Program Status to include.  You can also select multiple statuses by holding down the CTRL key as you select them.

Program Generic Types (template type) - You can leave the default of "All" or select a Program Type to include. You can also select multiple types by holding down the CTRL key as you select them.

Business Segment - You can leave the default of "All" or select a Business Segment to include.

Discount Identifier - You can leave the default of "All" or select a Discount Identifier to include.

Geographic Filter - You can select the radio button for a geographic category (region, for example) and then narrow the search further by selecting a specific sub category.  Or leave the selection at none to include all.  Note that if you filter by zone, programs that have no zone will not be included in the report.

Customer Filter (used for primary grouping) - You can select the radio button for a Customer category (Distributor, for example) and then narrow the search further by selecting a specific sub category. Or leave the selection at none to include all.  

Select the report output type (select the radio button for HTML, Excel, or CSV).  If you select HTML, the report output displays on the screen.  If you select Excel or CSV, you are prompted as to whether you want to view or save the report.

Select the primary and secondary report grouping levels: Status, and Program Type.

Select one or more column headers to include on the report: Provided you have not selected a geographic or customer filter, you can select headers by Projected Volume, Projected Expense, and/or Projected Margin.

The report shows your selection criteria at the top of the report.  Columns may include Status, Program Type,  Program Number, Program Title, Start Date, End Date, Projected Volume, Projected Expense, and Projected Margin.

If you click the [show report] link, the report prints to screen but is not saved or scheduled.  Use the [Save As Report Schedule] to save and schedule the report.  To save as report schedule, you enter the start and end dates the report should cover; the time of day you want the report to run; the frequency interval (Once, Daily, Weekly, Monthly), and you can enter or select the email addresses of the people whom you want to receive the report.

 

Product Summary -

Select the criteria to include for this report, and then click the [Save As Report Schedule] link or click the [show report] link at the bottom of the page.

This report has similar selection criteria as the Program Summary; refer to the description of the Program Summary above.

Note the relationship between Product Filter selections and column headers: You cannot select a column heading unless you have selected a product filter.

 

Margin Analysis -

Choose whether you want the margin report to be based on the margins for a product, or for a program.

This report has similar selection criteria as the Program Summary; refer to the description of the Program Summary above.  Note the Margin selections, which are different from the other reports.

"All" shows you all margins; if you select Between, to additional fields display so you can enter the beginning and ending margin range to include.  If you select Greater Than or Equal To, enter the amount for which you want to see margins that are equal to or greater than that amount.  Similarly, for Less Than or Equal To, enter the amount for which you want to see margins that are equal to or less than that amount.

Use the Sort selections to control the order in which the data for Status, Program Type and Margin is sorted.

Select the criteria to include for this report, and then click the [Save As Report Schedule] link or click the [show report] link at the bottom of the page.

 

Saved Reports -

You can save your report selection criteria for the summary and margin analysis reports, using the [Save As Report Schedule] link at the bottom of each report selection criteria page.  You can access saved report criteria and scheduling by simply clicking the Saved Reports tab and clicking on the desired saved report.  You can also deleted saved reports from the Saved Reports page.
