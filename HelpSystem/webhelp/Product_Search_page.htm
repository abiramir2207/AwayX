Product Search page

 Blacksmith Applications, www.blacksmithapps.com

 

The product search page displays when you click the [add products] link (when you are creating a program and you add product components, for example).

Use the drop-downs to narrow your search results.

Product search drop-downs may include:

Group

Product Item Group

Product group

Brand

Status

Product# [create list] - Enter a product number directly to search on it, or, use the [create list] link to dynamically enter products.

Description - enter a product description to search on.

Search Products From - select a discount type category within which to search for the products if desired or leave the default to search all.

Invoices (past 180 days) - Click the search icon to display a distributor search/select customer pop-up window in which you can select a customer on which to search for an invoice.

Sold To - enter a Sold To name to search on.

Within - select the time period within which to search.

[search products] - click the search products link to search using the criteria you selected.  When the product list is displayed, use the links at the bottom to finish your selection process:

 [import selected products] [import all returned products] [remove all selected products]

[reset] - use the reset link to clear any search selections you have made.
