Claim Reports (Tools)

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Tools > Reports Central > Payables/Billbacks

When you select the Claim Reports link, the Report Writer page displays.  Each of the report options listed under Payables/Billbacks appears on a report writer page tab.  The Generate Excel Document option must be selected from the Payables/Billbacks menu.

Select the type of information you want to report on by selecting one of the tabs:

Claim Summary

Variety Summary

Processing Time Summary

Participation

Cost Savings

For each tab, the same report selection criteria display, grouped by Billback and Geography.  For any criteria field for which you do not make a selection, the report pulls in "all" items.  Use these criteria to fully control the report output.

Within Billback, you can enter a specific Customer Invoice #, Vendor ID and Check #.

For the Billback dates (Billback Date, Billback Delivery Start Date and Billback Delivery End Date), you can select operators (greater than or equal to, equal to, or less than or equal to) and then select a date against which the operator will be applied.

You may enter a specific Customer Name and/or Operator Name, and you can restrict the report to a Claim Amount (using the operators: greater than or equal to, equal to, or less than or equal to).

Next, you can select a particular Claim Status, and Program Template type.

Within Geography,  you can narrow the report to specific Divisions, Regions, and/or Territories.

Additionally, you may be able to Group the report output according to  Program, Region or Customer.

 

Claim Summary -

The Claim Summary Report includes columns for Customer Account, Payee Name, Region, Market, End User, End User Name, Claim No., Total Cases, Claim Total, Reference, Entry Date, POD From, POD To, User ID, Hold (yes/no) and Status.

Totals and Grand Totals are included.

 

Variety Summary -

The Variety Summary report includes Program ID, Program Name, Claim No., Delivery Period, Distributor Name, Distributor ID, Region, Claim-Case, Claim-Dollar, Paid-Case, and Paid-Dollar.

Totals and Grand Totals are included.

 

Processing Time Summary -

The Turn Around Time Detail Report includes Customer Account, Name, Region, Market, End User, Name, Claim, Total Dollars, Total Cases, Postmark Date, PD vs RD Variance (Paid Date vs Receipt Date Variance), Receipt Date, RD vs ED Variance (Receipt Date vs Entry Date), Entry Date, CD vs ED (Check Date vs Entry Date), Check Date, and CD vs PD (Check Date vs Paid Date).  

Per the legend:

PD vs RD denotes Receipt exceeds 5 days from postmark date.   

RD vs ED denotes Entry exceeds 20 days from Receipt Date

CD vs ED denotes Check exceeds 3 days from Entry Date          

CD vs PD denotes check exceeds 27 days from Postmark Date

 

Participation Report -

The Participation Report includes columns for Region, Market, Distributor Account, Distributor Name, Item, Description, Field Exec. Cases, Field Exec. Dollars, Bid Request Cases, Bid Request Dollars, Operator Direct or HQ Programs Cases, Operator Direct or HQ Programs Dollars, Distributor Trade/Shelter Cases, Distributor Trade/Shelter Dollars, Operator Deviated Pricing Cases, Operator Deviated Pricing Dollars, Total Cases, Total Dollars.

Totals and Grand Totals are included.

 

Cost Savings -

The Cost Savings Detail Report includes columns for Account, Name, Region, Market, End User, End User Name, Claim, Reference, Credit Memo, Claim Dollars, Distributor Dollars, +/- Dollars, Claim Units, Distributor Units, +- Units.

Totals and Grand Totals are included.

 

Generate Excel Document

When you select the Generate Excel Document link from Payables/Billbacks on the Reports Central page, a Claim Excel Report window displays in which you can select a claim status on which to report.  Click Generate Report to create the excel report, excelgen.xls.

Columns included in the excel document include: Sold To# ,Sold To Name, Operator #, Operator Name, Program ID, Program Name, Item Number, Item Description, Item Paid Volume (CS), Item Paid $, Billback Date, Claim Start Date, Claim End Date, Check #, Vendor #, Vendor Name, Status, Division, Region, Territory, Postmark Date, Receipt Date, Entry Date, Transaction Date.
