Upload GL Code settings

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings > Payables >  manage GL code > upload tab

URL Properties:  GL_Code/Upload_Gl_Code/index.cfm?Show_Tab=3

When you click the upload tab, the standard Stored Records/Edit Record page displays with information specific to GL code data.

Use the [create new entry] link to enter a new GL code upload entry in the Edit Record section.

When you click the [create new record] link, the Edit Record section displays a Select Upload File field with a [Browse] link that permits you to locate the upload file.  It also includes a link to [upload data].  Use the Activate On (calendar) icon and the Fiscal Year pulldown to complete the information for this GL code upload.

Columns

Uploaded By - This is the Id of the user who uploaded this GL code record.  If you click this link, the upload record displays in the Edit Record section.  

You can change the activate date using the calendar icon and click the [save changes] link.

Click the [view] link to see the GL code record.

Fiscal Year - The Fiscal Year associated with this GL code record displays, and is not editable.

Activate On - The Activate On date that was selected for this GL code record displays.  You can change this date by clicking the link under Uploaded By and using the calendar icon in the Edit Record section.  The Activate On date allows you to set up GL code information at any time, and control when it becomes active within the system.

Status - The status of this record displays.  A green checkmark means it was uploaded; a red "x" means the upload failed for some reason.   

Active - A red square in this column means the data from this upload is currently active in the system based on the activation date.
