Active Program options

 Blacksmith Applications, www.blacksmithapps.com

 

Assuming you have permissions, you see the following options for an Active program:

 

print

email

fax

copy - If you click copy, a prompt asks you if you are sure you want to copy this program.  If you click OK to copy the program, the system copies the appropriate program fields, gives the program a new id number, and locates you to the Basic Program Information page so that you can enter the remainder of the information for this new copied program.

roll over - If the program dates indicate that the program is eligible for roll over, this option is enabled.

history - The program history page shows you who did what, and when, regarding the program.  Click the [return to view program] to close the program history page and return to the program.  

cancel - If this link is enabled, you can cancel this program.

revise - If you click revise, a prompt displays asking if you are sure you want to revise this program.  If you choose to revise the program, it will be moved out of Active status and back to "not approved".  After you save your changes, the program will show in the WIP tab.  After you revise a program, a new option displays, "revision history".

 

You can hover over some of the options to see who Created the program, Requested Approval for it, or Approved it.

If a program has been revised, there is an option for revision history.  Click revision history to see a pop-up with a link to each program revision (the pop-up shows you the Revision Version, Contract Title, Contract Start Date , Contract End Date, Created By, Approved By,  and Approved.

reset - When the reset link is enabled, you can reset the program's status back to WIP.  

 

The options below will not be enabled unless you are an admin level user:

delete

purge
