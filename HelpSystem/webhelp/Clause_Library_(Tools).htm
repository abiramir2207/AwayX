Where can I find this in FORGESM?

Home > Tools > Clause Library

Use the Clause Library to view, create, edit and control how clauses are used in programs.

There are three tabs on the Clause Library page:

Search Category -

This searches and lists the clause categories.  Each clause category is listed and shows the Clause Category name (click the name of the clause category to display it in edit mode), whether Revisions require approval, whether there is a Default Clause (click it to display the clause in view mode), and a Delete Category link.

Click a clause category to open it in Edit mode (see Edit Category, below).

 

Create/Edit Category -

This tab says Create Category if no clause category is selected; if you select a clause category (by using search category and clicking a category) this tab says Edit Category.  

Click Create Category to display an entry box in which you enter the new Clause Category Name.  Note the checkboxes: You cannot select the Required for all programs checkbox for a category until you add a default clause.  You can select the Revisions Require Approval checkbox, however.  Once you've added the category name, click save, and your new category displays in the listing.

Select your new clause category from the list, and click the [add clause] link.  A tab called Create Clause displays with a text editor window, in which you can enter and format the clause.  You can select the Set as default clause checkbox (if you make a clause the default for a category, you cannot delete the clause).

Once you save the clause text, the checkbox for Apply this change to current programs is enabled.  If you select this checkbox, any programs that are not yet approved, for which this clause category is selected, will have this clause added.

Once you have saved a clause, you can click on the clause to display a tab called Edit Clause, with the text editor window.

 

Search -

This tab lists all clauses by default, and lets you search clauses by category.

Clause Library Search - Category pull-down - To display all Clauses, leave the pull-down at "Select Category"; to restrict the search to a particular clause category, select the category using the pull-down.

Body - Leave this blank to include any and all clause text in the search, or enter any piece of clause text to search on. To clear your search selections, click the [reset form] link.  Click the [search] link to execute your search.

The search results display, with a row returned for each clause that meets the search criteria.  The results show the Category (which you can sort on by clicking the triangle), and a Body Excerpt from the clause.

Clause search results icons:  

To the left are icons that allow you to Edit the clause (click the pencil icon, and an Edit Clause tab and page display with a text editor for the clause body text) and to View the clause (click the magnifying glass).  On the Edit Clause page, note the checkbox that allows you to Apply this change to current programs; another checkbox allows you to indicate this clause as the Default for this clause category.
