The Control Panel is the heart of the application.  This is where your organization controls who can see what within your system, as well as where you can configure FORGESM components including those listed below, for your business.

There are seven main areas within the Control Panel: within each of these areas, your access depends upon your permissions settings.  Please note that not all of these settings will be relevant for all users.

Geography -  Use the Geography area to view, enter and select geographical entities such as territories, divisions, regions, areas, and to work with operators (including creating and assigning positions and categories).   

Use the geography settings to mirror your organization's business.  These geographical settings are used in another part of the application, when you create user positions.  Your geographical entities display in a hierarchical position tree, and you can assign use positions to the geographical levels.

Projects - Use the Project administration area to display, edit and create the status of your projects (i.e., those to which you have access, based on your role), the priority of your projects, the project functional areas and sponsors.

Payables - Use the Payables administration area to display, edit and create settings related to  Billbacks and Deductions.  These may include billback tolerance, billback age warnings, billback holiday management, payables fund settings (fiscal year), payables GL settings including uploads, gl codes for payables, payables product uploads, deductions action list activities and age ranges, and more.

Programs - Use the Program administration to control program expiration settings and to view and work with the program wizard.  You can also work with program components such as formula rules, lump sum names, discount identifiers, document management, margin components, pricing components, and so on.

Password -Administrators use the Password link to change their passwords (other user's password are reset in the "user" section.

Administration - This is where senior administrators can adjust the application to suit your business needs.  If you are an Administrator level user, the Control Panel displays showing the "Access Rights" levels that are currently selected for each Control Panel area.  If you have permissions, you can change these access rights settings using the [Maintain Access Rights] link.

Click the [Maintain Access Rights] to display a page showing the Control Panel with the access right drop-down for each area.  The link changes to say [Update Access Rights].

The access rights are Low, Medium, High and Admin.  You might create multiple Admin users, with different access rights within the Control Panel.  Remember that in the User Profiles page, you can assign each user profile to a Control Panel access level of None, Low, Medium, High or Admin.

Users -   User links effect settings relative to a user.
