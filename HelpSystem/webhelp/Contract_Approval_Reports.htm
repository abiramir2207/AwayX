Program Approval Reports

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?         

 Home > Tools > Reports

 

The Program Approval Report (Average Days to Approve) allows you to generate a report showing Approval statistics on a per-user basis.

 

To run the report:

  1. Choose the start and end dates for the report
  2. (Optional) Select a user profile to filter the results
  3. Click the [run report] link.

 

Report columns include the following:

Name     # of Approved     Percent of Programs Approved     Average Days to Approve

(of User)   (Programs)

 

Totals are included.
