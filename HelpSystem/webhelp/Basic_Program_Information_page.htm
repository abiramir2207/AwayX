Basic Program Information page

Where can I find this in FORGESM?

Home > Create program > Select Program Type   OR

Programs Scorecard > (click program link)

Depending on the program template that was used to create the program, the fields you see and the verbiage on the screen may differ significantly from the example presented below.  However, the general concepts are applicable to all programs.

When you create a program, the first page that displays is the basic info page.  The left pane reflects which page you are on and shows the remaining program pages. In this case, basic info is in red bold type.  In future, when you return to this program in edit mode, the left pane will show completed program pages in blue text with a green dot, incomplete pages in blue text with a red dot, and the page you are on in red, bold text.

Program ID: The program ID is automatically assigned by the system.  

Discount Identifier: The discount identifier may be automatically filled in based on the template from which the program was created.

Program Reference Number: Enter a program reference number to identify this program to your other systems (such as an ERP identifier, for example).

Responsible Sales Person: The name of the user who is creating the program is automatically filled in.

Program Title/Description: Enter a meaningful program Title and Description here.  You will be able to search and sort on the title.

Equipment/Dispenser Placement: If this program involves equipment, select this checkbox.

Program Span: Select the dates, using the calendar (you can also key them in directly)  over which this program will run.

Auto Renewal: If you select auto renewal for this program, two additional renewal related fields appear:

Days before start date to activate as ready for approval

Renew Annually, or Concurrently (after this one has completed)

Renew Concurrently means with no lapse, as for a program that runs the entire year.  For example, if you have a program that runs from August 1 to September 1 2005 (31 days), and you select Concurrent renewal, the renewal program will run from September 2 to October 3.

Renew Annually can be used for programs that repeat for a span of time (such as a program that pertains to the same three months every summer).  Using the program example above where the program runs from August 1 to September 1 2005, the annual renewal program would run from August 1 to September 1 2006.

Program Quantity: Enter the number of units in this program, and select the type of units (case or pounds).

Controllable: Indicate using the radio buttons whether the program volume should be controllable by the sales people.

Claim Mechanics: Use the drop-down to select the method distributors should use to claim program benefits.

Advanced Spending Amount: Enter the amount to allow for use in advanced spending for this program.

Pay fields: You may have the payment made out to one person and sent to another.  Use the two pay sections to control who the program payment is made out to, and where and two whom it is sent.

If you choose to make payable to other than the distributor, for example, you can have the payment sent to the same address or another using the Send Payment To fields.

Payable To:

Pay to Distributor - If payment is to be made to the distributor, select the Pay to Distributor checkbox.  The other "pay to" fields become grayed out when you select the Pay to Distributor checkbox.

If payment should be made to other-than the distributor, leave the Pay to Distributor checkbox deselected and fill in the Pay to fields:

Company Name

Attention

Address 1 & 2

City, State, Zip

Payable to Comments

 

Send Payment To:   

Send to Broker - If you select the Broker checkbox, the remaining address fields become grayed out.

Same as Payable To - Use this checkbox to have the payment sent to the same entity as indicated in the Payable To.

To enter a different address to which to send the payment, leave both the Send to Broker and the Same as Payable To checkboxes deselected.

Company Name

Attention

Address 1 & 2

City, State, Zip

 

Notes:  Enter any notes that you want your clients to see in the Notes section.

Comments: Enter any comments that you do not want clients to see in the Comments section.

 

Click continue to save the program. The Select Program Customers page displays.  Once you click [continue] to save, the program has been saved and if you exit the program or the application, the program will be retrievable from your Work in Progress folder at any time.

If you are editing a previously saved page, the link says [save changes] rather than [continue].
