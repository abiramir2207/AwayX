Where can I find this in FORGESM?

Home > Tools > Volume Reports

When you select the Volume Reports link from the Tools options, the Report Writer page displays showing the Volume Summary Report section.  The volume summary report information shows all of the selection criteria that you make on this page, so that you know exactly what is included in the report.  Included along the top of the report are Date Span Criteria, Distributor Criteria, Product Criteria, and Date Details for the fiscal categories.  Totals are included.

For each Fiscal category (Current Period, Current Quarter, Current Year) the following data is included: Actual Dollars Invoiced, History Dollars Invoiced YAG, Variation Dollars, Variation Dollars %.

Date Span Criteria - Use the calendar to select the date span; the date defaults to today's date, and the span is from the fiscal period start date.

Fiscal categories: Select or deselect the checkboxes corresponding to the fiscal reporting categories you want to include (all three are selected by default, and clicking the reset link selects the three checkboxes):

Fiscal Period - You cannot deselect this checkbox.

Fiscal Quarter - Deselect this checkbox to omit volume reporting by fiscal quarter.

Fiscal Year - Deselect this checkbox to omit volume reporting by fiscal year.

 

Customers Criteria - (The Customer Criteria display provided the Distributor filter checkbox is selected). These default to "All", except for Ship To; clicking the reset link resets these to "All", and clears the Ship To field.  Use the drop-downs in each of the categories to control the information included in the volume report.

Save As Report Schedule - click the right-facing blue arrow icon to display the report schedule fields.  You can give the report a name, select the report interval (once, daily, weekly, monthly), select a start and end date and time of day.  Use the Email address box to select the recipients for the scheduled report.
