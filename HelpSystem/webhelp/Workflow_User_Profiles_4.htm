Workflow: User Profiles 4

 Blacksmith Applications, www.blacksmithapps.com

User profiles allow you to control exactly what a user can see and do within FORGESM.  

You can create user profiles with extremely limited permissions to suit a specific circumstance (perhaps the desire to allow broker to view certain material), thus protecting the confidential nature of your data.  And you can create profiles for superusers and many permissions levels in between.  Anything is possible: control who sees which price list, and so on.
