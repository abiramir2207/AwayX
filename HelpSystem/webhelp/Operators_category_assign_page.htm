How to use this page

Use the Operators - category assign page to select an operator category, and then search for operators you want to assign to that category.  Operator categories can be used to restrict an operator to certain categories (such as restaurant, fast food).  

A recap of operators, users and positions illustrates how the operators and users can be cross referenced by the system.  In settings, geography, you can assign operators to positions, optionally using operator categories to qualify what categories the operator includes.  In settings, Users, you assign users to permission profiles and positions.  You assign both operators and users to positions, and the system uses only the assigned categories when determining what that user can create or access.

Click the [select operator category] link to display the operator Category Name page.  

Select a category by clicking a radio button, and click the [import selected records] link.  

The Category- Assign page redisplays showing the category you selected, with an additional link in the right-most column called [view operators].  Click this link to view the operators associated with this category.  

The Category Operators listing displays.  You can sort by any of the columns on this page by clicking its column link at the top (for example, clicking the [# of Locations link] sorts by the number of locations and presents you with the triangle with which to reverse the sort order).

Columns include Operator Name, Location Type, City, State, # of Locations, Doing Business As, and Position.  

After you view operators, return to the category assign page and search operators.

Click the [assign] link to assign an operator to a category.
