User Profiles - from Settings, Users

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings Control Panel > Users > user profiles

URL Properties: settings/Access_Rights/index.cfm?PageTitle=Users: user profiles

Overview

User profiles is where you set the permissions levels by creating permissions profiles called user profiles.  You then assign the appropriate user profile to a user when you add or edit a user (a user is assigned only one user profile).

When you display the user profile page, any existing profiles display across the top of the page, showing  the profile abbreviations.  Use the scrollbar to scroll to the right to see all profiles, if you have more than will fit on the page.  If you add a new profile, it is added at the far right.

To add a new user profile, click the paper and pencil icon, located at the upper left of the page.

The Create a New Profile window displays, and you can enter a Profile Label and Abbreviation and click save.  It may take a minute to add, but when it finishes adding the profile, the User Profiles page re-displays showing the new user profile in the far-right column.

Select and assign permissions for this profile as appropriate.  Permission categories are broken out by Programs, Billbacks, Deductions and Administrative Control Panel (described below), and some of the permissions categories you see may differ from, or include more or fewer than, the ones described below.  If you want to assign a profile with rights to approve any amount regardless of an upper limit, enter an asterisk in the amount field.

Programs

See the Program-related User Profile Approval Rights topic for details on the many program approval related profile settings.

Billbacks  

Create Billback - Indicate using a checkmark whether the user profile should be able to create billbacks.

View Deviation - Indicate using a checkmark whether the user profile should be able to view deviations.

Approve - Indicate using a checkmark whether the user profile should be able to approve billbacks.

Approve Deviation Amount - Enter the deviation amount, if applicable, that the user profile should be able to approve (enter the amount of deviation).

Approve Total Amount - Enter the total amount (including deviation) that the user profile should be able to approve.

Approve Critical - Indicate using a checkmark whether this user profile should be able to approve critical billbacks.  Critical billbacks are billbacks for which the payee is unknown or the program does not exist in the system.

Delete Billback - Indicate using a checkmark whether this user profile should be able to delete a billback.

Deductions

Approve - Indicate using a checkmark whether the user profile should be able to approve deductions.

Approve Amount -  Enter the amount that the user profile should be able to approve.

Reassign Deductions - Indicate using a checkmark whether the user profile should be able to reassign deductions amongst users.

Delete/Undelete Deductions - Indicate using a checkmark whether the user profile should be able to delete as well as undelete deductions.

Administrative Control Panels  

Commodity Settings - Indicate using a checkmark whether the user profile should be able to view or change commodities information from Home, Programs, [commodity costs] link (this link displays a page showing commodity data sources, and pricing rules).

View Price Rule - Indicate using a checkmark whether the user profile should be able to see pricing rules in Settings, Control Panel, Programs, formula pricing rules.

Create/Edit Price Rule - Indicate using a checkmark whether the user profile should be able to create and edit pricing rules in Settings, Control Panel, Programs, formula pricing rules.

Report Scheduler - Indicate using a checkmark whether the user profile should be able to schedule reports from report screens such as Tools, Volume Reports (Volume Summary Report) and Performance Indicators (Program Performance Report).  If the user profile can schedule reports, they will be able to select the schedule (date, time, report interval, who should receive it, etc.).

Reports Access Level - Indicate using the drop-down whether the user profile should be able to access the Reports options at all (if not, select None), and if they should have access, whether their access should be Low, Medium or High.

Settings Control Panel - Indicate using the drop-down whether the user profile should be able to access the Settings Control Panel options at all (if not, select None), and if they should have access, whether their access should be Low, Medium, High or Admin.

Project Management Access - Indicate using a checkmark whether the user profile should be able to view, create and edit projects.

Project Reassign Access - Indicate using a checkmark whether the user profile should be able to reassign projects.

Clause Library Access - Indicate using a checkmark whether the user profile should be able to access the Claus Library from Tools, Clause Library.

Program - Edit/Remove Required Clause - Indicate using a checkmark whether the user profile should be able to change or remove a required clause from a program template using the Clauses tab in the program wizard.

Price List Access - Indicate whether this user profile should be able to access the price lists.

View Special Price List - Indicate whether the user profile should be able to view any special price lists, if you have different price lists for different customers.

Create End User Access - Indicate whether this user profile should be able to create end users with access rights.
