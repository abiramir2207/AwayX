Program Summary page

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Search program   OR   Scorecard > (click program link)

When you display an existing program, the Program Summary page displays.  

Initially the program displays in Read Only mode, as indicated at the upper left of the page.  Provided you have adequate permissions, you can toggle between Read Only and Edit mode by clicking the link beneath the current mode: [Click for Edit] or [Click for Read Only].

From the Read Only program summary page, you can view the program details, and print, email or fax the program summary.  You may also View Margins (provided you have permissions and volume has been applied).

If you are in edit mode, you can click any of the active links along the left side of the page to display and work with the page, and if the program entry is complete enough, you may click View Margins (if you have permissions), Volume (this displays the Volume Applicator page) and the Ready for Approval checkbox (these items appear across the top of the page).  You will not be able to click the View Margins or Ready for Approval checkbox until you have applied volumes to all items (products).

Note: The Ready for Approval appears only for WIP programs.
