Clauses:  program template page four

The Clauses template page allows you to search for and include clauses that will be selectable for programs created using this template.  Clause categories and clauses available for inclusion are created by users with adequate permissions on the Home, Tools, Clause Library pages.

Types of clauses can include General, Rebate, Lump Sum and Growth, based on the program template, and they can be Required (R) or Optional (O). A clause that you indicate as required will be required on a program created using this template.

If you click the [Search Clause] link, the clause library search page displays, and you can search for any clause that exists in the clause library.

When the selectable clauses display, you can opt to include all default clauses for all clause categories by selecting the checkboxes for all categories, or you can select individual clause categories (the default clause is automatically selected).  For clause categories with multiple clauses, you can select a clause other than the default.
