Add Users - from Settings, Users

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings Control Panel > Users > add users

URL Properties: settings/Access_Rights/users_create_form.cfm?PageTitle=Users: add user

Use add users to create a new user and enter their phone, email, fax and address information, as well as to select the appropriate user position and user profile for the individual, and to assign the person to business segments, type or class codes, etc., if you use them.

Fields on this page

 

User Positions -

Select Primary and Secondary positions - Click the [Select Primary and Secondary positions] link to display a listing of all user positions that exist in your system.  Click the [currently selected positions] link to toggle the view of positions to show already selected positions separately from those that are not selected.  Positions that have already been selected for other users display with a checkmark.  More than one user can be assigned to the same position.  You do not have to select secondary positions for any user.

When you pick a primary position for a user, this is the position that determines this person's position in the hierarchy of positions within your organization; when you select it, the add user page refreshes showing this position.  The user positions from which you are selecting are the user positions that display in the user position tree that displays when you click settings, users, user positions.

If you select secondary positions for this user, the user will also see notifications associated with those other user positions in addition to their primary position.  You may or may not want a Headquarters level position to have secondary positions assigned so that the headquarters user also sees and is notified about positions under him/her, for example.

Use the 3 links at the bottom of the page to work with the selected user positions: [import selected positions], [import all returned positions], or [remove all selected positions].

User Profile -

A user can have only one user profile.  Your administrator will have set up the user profiles needed by your organization within Users, user profiles.  If you have permissions, you can view the details of user profiles by selecting the [user profiles] link.  Select the user profile that is appropriate for this user with the drop-down.

Business Segments/Class Codes/Type Codes -

Depending on your setup, you may see this or some other business-related breakout.  Your organization may use a breakout such as this to tie programs to business segments or class codes (and through user profles, users have access to the programs that are part of the class codes/business segments for which they have permissions).  Select the area to which this user should have access.

Enter the informational fields specific to this user:

First Name, Last Name

Company (if applicable)

Title

Addresses 1 and 2

City, State and Zip

Phone, Fax, Email

 

When you click save settings, a page displays showing the user information you entered along with a new password and the message that the user creation was successful.  Use the link called [return to user listing] to display the page listing all users.  The new user should be listed.

The system sends the new user the password to the email address as it was entered on the add user page, and the user can log in and change the password.
