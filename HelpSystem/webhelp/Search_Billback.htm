Billback Search

 Blacksmith Applications, www.blacksmithapps.com

 

Billback Search -

Hide Billback Search/Show Billback Search: Click the little triangle to toggle between hiding and searching the billback search criteria.  You may want to hide the search criteria to see more search results. Whether you enter some, all or no criteria, use the [search billbacks] link to execute the search.

Title: Enter a billback title or partial title to search on.  

Payable #: Enter the system-generated Payable Number for a billback.  

Billback #: Enter the billback # given by the distributor or operator.  

Status: Select a billback status to search on using the pull-down.

Billback Date, Start Date, End Date: You can search on any combination of dates, and you can use the operators with the dates (Greater than or Equal to, Equals, and Less than or Equal to).  To specify the date component, use the calendar or enter the date (you must enter four digits for the year).  

Claimed Amount:  Select an operator (Greater than or Equal to, Equals, and Less than or Equal to) and enter the billback amount.

Aging: Select whether to search all billbacks, or to search only aging billbacks, or only billbacks that are not aging. Your administrative settings determine the number of days after which billbacks are marked as aging.  

Customer Name: Enter the name of the customer to search on.

Territory Name: Select the territory to search on, using the drop-down.

End User Name: Enter the name of the end user to search on.

Program Status: Select the program status for which you wan to search for billbacks.  

Program Generic (template) Type: Select the program template type for which you want to search billbacks.

Program Number - Enter the program id number to search for billbacks for the specific program.

Reset Form: Click [reset form] to clear any search selections you have made.

Search Billbacks: Click the [search billbacks] link to execute your search criteria.

 

Billback Details - When you click a payables/billback link, the individual billback details display.

The billback summary page displays in read-only mode (if you have permissions, you can [click to edit] the billback).  The billback amount displays highlighted in green at the upper right, next to the description of the billback (including the system-generated billback payable id, the date, Payee, Title and so on).
