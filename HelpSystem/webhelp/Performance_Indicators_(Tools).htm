Performance Indicators (Tools)

 Where can I find this in FORGESM?

Home > Tools > Performance Indicators

The Program Performance Report runs for the current date, and includes programs for template types that have been selected by the administrator.

The report includes, for each program listed that meets the criteria, the performance index, the program name, ID, effective dates; Volume per unit of measure showing the percentage of Target v. Actual, and the percentage of time relative to the program span.

You can change the report output dynamically by clicking the right-facing red arrow and selecting a specific program status.  You can also change the Volume, Time and Index operators (less than or equal to, equal to, or greater than or equal to), and percentage values.

You can change the sort order of the report results by clicking the Program header link.

Save As Report Schedule - click the right-facing blue arrow icon to display the report schedule fields.  You can give the report a name, select the report interval (once, daily, weekly, monthly), select a start and end date and time of day.  Use the Email address box to select the recipients for the scheduled report.
