Create new futures pricing (Home, Programs)

Where can I find this in FORGESM?

Home > Programs > Futures pricing > create new

 

When you initially display Futures Pricing, a tabbed page displays with tabs for: Initial Request, Raw Requirements, Procurement Quote, Pricing, Price to Sales, and Expired.  Click to see a sample image of the futures pricing page.

Use the [search futures pricing] link to search for existing futures pricing entries, or click [create new] to enter a new futures pricing entry.

 

When you select [create new], the futures pricing page displays in "Phase 1 - Initial Request" mode.  The left pane shows the other futures pricing phases.

 

Request Name - Enter a meaningful name for this futures pricing request.

Request Description - Enter a description for the futures pricing request.

Request Dates - For a new request, the date fields (Start Date, End Date, Customer Deadline Date) will be blank.  Click the [edit dates] link to select the request dates, and use the [apply] or [cancel] links to save and apply them or to cancel.

Products - Click the [get products] link to select products for the futures pricing request using the product search page.  Click [add new products] to enter new products for this pricing request.

When you import the selected product, the Initial Request page displays showing the products you selected.  

Choose whether to apply periods by calendar or fiscal year and click [apply].

For each product you selected, enter the volume, select the uom, and delivery type.

Click the [distribute evenly] link to distribute the amounts evenly; use the [reset] link to clear the entries and try again.

Next, choose the Distributors/customers using the [get customers] link (this displays the familiar distributor search page).

Choose Operators using the [get operators] link (this displays the operator search page).

Click the [save only] link to save your entries on this initial page, or use the [save and forward] link to save and forward the page to a marketing user(s).  If you forward it, you will not be able to access it.

When you save, the system fills in and displays some of the fields with the entries you've made.
