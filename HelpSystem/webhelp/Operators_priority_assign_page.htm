Settings Control Panel > Geography > Operators > priority tab

Columns on this page:

Operator Priorities (select operatory priority)

Operators (search operators)    

How to use this page

Use the links at the top of this page to [View Priority], [Create Priority], and [Assign Operators].

Use the Operators - priority assign page to select an operator priority, and then search for operators you want to assign to that priority.

Click the [select operator priority] link to display the priority name page.  

Select the priority by clicking a radio button, and click the [import selected records] link.  

The Priority - Assign page redisplays showing the priority you selected, with an additional link in the right-most column called [view operators].  Click this link to view the operators associated with this priority.  

The Priority - Operators listing displays.  You can sort by any of the columns on this page by clicking its column link at the top (for example, clicking the # of Locations link sorts by the number of locations and presents you with the triangle with which to reverse the sort order).

Columns include Operator Name, Location Type, City, State, # of Locations and Doing Business As.  

After you view operators, return to the priority assign page and search operators.

Click the [assign] link to assign an operator to a priority.
