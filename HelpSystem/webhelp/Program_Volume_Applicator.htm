Program Volume Applicator

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Programs (click a program link) > click program > edit mode > click Volume

From the Program Summary page, click the [Volume] button to display the Volume Applicator.

Use the Volume Applicator pages to indicate the program volume (and cap if desired), for each product in this program.

The system presents a calculated volume based on your program entries. To use this volume, click the [apply volume] link beneath the calculated volume.

Or, to enter a volume by item, use the checkboxes to select items that will have the same volume, and then enter the volume in the Enter Volume per Item field.  Click the [Apply Volume] link under the volume per item field, and the value you entered for volume per item displays next to the items whose checkbox you selected, for both Case and Pound.

To enter a cap, simply enter a value in the volume per item field and click the [apply cap] link.  The value you enter for the weekly cap displays in the right-most column next to the selected products.

Continue to enter volume per item until all products have the appropriate volume.  You have to apply volume to all items in the program before you can View Margins or select the Ready for Approval checkbox for a program.
