Workflow: User Properties 5

 Blacksmith Applications, www.blacksmithapps.com

The power of User Positions (the positions you import to FORGESM with a data feed) and the User Profile (which you create to suit the different levels of permissions you need in your organization) come together when you create users in FORGESM.

Users can have primary and secondary positions, but can have only one user profile.  Together, the position and profile determine what the user can see and do within FORGESM.
