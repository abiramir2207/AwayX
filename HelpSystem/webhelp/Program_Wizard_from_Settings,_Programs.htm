Program Wizard from Settings, Programs

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?                                

Settings Control Panel > Programs > program wizard

Use the program wizard to create, view and edit program templates, provided you have permissions.

Note: Even if you have permissions to delete a program template, use extreme caution.  If you delete a program template, users will not be able to create programs for that template.  However, any existing programs that were created based on a template you delete will not be affected, and will continue to work.

The program templates supplied with FORGESM can be customized by an adminstrator-level user within your organization.  

When you display the Program Wizard page, some of the program template rows may display with a gray background.  This means the program template has been created but not yet activated.  You might create a program template and choose not to activate it because you don't want it to be used until a certain date in the future.

Or, you might begin creating a program template, fill out the first page of the template and save it, and then need to do something else.  Once you have saved the first page of a program template, it displays in the program wizard page with a gray background, and you can come back and work with it later by clicking the [edit] link next to it.  The [Activate] link will not appear for a program template on the program wizard page until you have saved all pages (for example, if the last page of a program template only has options you don't use - such as clauses - you still need to save that page) before the system considers the template as eligible for activation.

Generic Type - The program template name, for example, Distributor Off-Invoice.

Program Type - The type of program for which to use this template.  For example, Volume Rebate Programs.

Description - A more detailed description of the program template.  For example, "Use this template for distributor local volume rebate programs that are paid quarterly".

Each program template type breaks out the template information as follows:

Basic Information

Restrictions - Lets you indicate general restrictions to enforce on the programs created with this template.

Options - Lets you indicate general options to make available on the programs created with this template.

Profiles Permissions selections for programs created with this template: Lets you assign permissions for profiles regarding access and approvals:

Allowed access to profiles (select the profiles that should have access)

Allowed approval to profiles (select the profiles that should have approval rights)

Allowed lumpsum approval to profiles (select the profiles that should have lumpsum approval rights)

Allowed Billback approval to profiles (select the profiles that should have billback approval rights)

The Distributor Off-Invoice and Distributor Trade/Shelter are used for distributors, and the Operator Direct, Operator-Deviated Pricing and Bid Request are used for operators.  

Field Execution can be used for programs that don't quite fit in either the distributor or operator program template categories that are provided.  For example, if you have a trade show coming up and you need to allocate monies for the show or for booth fees, you might use the Field Execution program template.

Note that your implementation of FORGESM may include more or fewer program templates than are included with the base system.  

Explain the details of the program template

Distributor Off-Invoice -

Use this program template to create programs that use a fixed price, i.e., a particular amount off the invoice.  Use this program template type for programs that will not involve billbacks.  

Distributor Trade/Shelter  -

Use this program template for trade programs.  This is a widely-used program template that allows you to offer a promotion to distributors.  This program template type is payable to the distributor, based on the volume they do with your product.

Field Execution -

Use this program template for programs that aren't served by the other program template types.  For example, you might use it for trade shows.   

Operator Direct or HQ Programs -

Use this program template for programs that pay the operator.  For example, if you have a promotion with a food chain to give them a discount per case on an item, that operator direct program provides for the operator to bill you back, and to be paid.  

Operator-Deviated Pricing -

Use this program template type to support programs where your distributor gets paid for what the operator purchases.  

For example, you offer an item for $23.00 per case to your distributor, and you offer the same item to a food chain for $22.00 per case.  In this type of program, any cases of the item that the distributor sells to that food chain will be billed back to you (by the distributor) for the difference (in this example, $1.00 per case).    

Bid Request -

The Bid Request program template type is available to Operators.  This program type provides for bids that may or may not be called upon to pay monies against.  

For example, you might use a bid request if you bid for a school district who says they want to purchase 100 cases of product.  Based on the manufacturer's best price per case on the product, the operator may or may not win the bid and the business.
