Deductions from Home page

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Billbacks > Deductions or Home > Deductions icon

URL Properties: deductions/scorecard.cfm?ScorecardToShow=age&ScorecardToShow_basedon=count&CurSel=1

 

When you click the Deductions icon from the Main toolbar, or when you click the Deductions link under Billbacks, the Deductions home page displays.

The deductions scorecard lets you display the deductions by age and deduction type, and set a default selection.  The drop-down selections are:

age, #of deductions

age, dollar

action, #of deductions

action, dollar

The bottom of the page includes a search deductions section where you can execute a simple search on deductions, or you can click the [advanced search] link to display many more search criteria to narrow your deduction search.  

The simple search lets you search by Deduction Number, Deduction Date (using the operators greater than, equal to, or less than), a dollar amount (again using the operators), Sold To (clicking the magnifying glass displays the search customer/distributor page), and Broker (clicking the magnifying glass displays the broker search page).  If you execute the simple search and more than one deduction meets the search criteria, the deductions are listed and you can click the deduction number of the row you want to display.

The right pane of the page shows you any reminders you have.

If you select to display the scorecard deductions by age, the deductions scorecard color-codes the deductions by age category, such as New, Open, Late and Unrecoverable.  Across the top of the page are the deduction types: New, Open, Request for Approval, Closed, Auto Closed, and Deleted.   The number of each type of deduction (or amount, if you chose age/dollar) displays in the appropriate columns and rows.

If you select to display the scorecard deductions by action, the deductions scorecard displays by Call Broker, Call Distributor, Check OS&D, and No action taken, with the same deduction types across the top (New, Open, RFA, Closed, Auto Closed and Deleted).  The number or amount of each action displays in the appropriate columns and rows.

You can click the counts in any column to display a page with the listing of deduction records.  Click an individual deduction record to show detailed information about the deduction (this is called Single Deduction View).

You can sort by any column header by clicking it: sort (and reverse the sort order by clicking again) by Deduction #, Amount/Customer, Age/Action, Broker Region and Analyst.

Use the bottom section of the page to search for deductions.
