Program Template Fields page one

 Blacksmith Applications, www.blacksmithapps.com

 

Note: The Distributor Trade/Shelter program template is used as a model in the following program template field description help topics because it is widely used and contains most of the fields found on the other templates.

Fields on this window

Basic Information

 

Field

Description

Program Template Name

The name for this program template type, for example, "Distributor Pricing Request".

Program Template Description

Enter a description for this template type that will easily identify it and distinguish it from others for your users.

Allow Customers

This is required for trade programs.

For other templates, you can select whether to Allow Customers, and whether Customers are Required, as well as whether customers should be restricted to Allow only One.

Allow Territory

If you select this checkbox, the program template will include an Allow Brokers notation, and programs created with this template will include a Territory Search page.

Require at least one discount

Select this checkbox if this program type should require at least one discount.

Enable Date Exclusions

Use this checkbox if your program template may be used for programs that require exclusionary date ranges.  

For example, you might have a program that offers some type of discount on turkeys, and you don't want this program to run during the Thanksgiving season.

Include Trade

Indicate whether to include trade in this program type's margin calculations using the radio button for Include Trade or Do Not Include Trade.

You may want to exclude trade if the promotion simply won't be profitable if both operators and distributors are included/eligible.

For example, if you have already offered a percentage off all items bought by your distributor, but you are also offering an operator a great promotion on an item, you would not want to allow both the distributor and the operator to claim on that item.

Exclude Trade Explanation

Enter the explanation as to why Trade is not included.

Discount Identifier

Select the discount identifier: for example, B(Bid), C(Chain) or O(Other).

Fiscal Year, A/R and Allocation

Select the fiscal year by clicking on it: the A/R categories associated with this fiscal year display in a pop-up window.

Select the A/R categories with which to associate this program type, and click the appropriate link: [import selections] [undo selections] [close].

After you use the [import selections] link, the template page displays showing your A/R selections (A/R id and description).  

Beneath each A/R selection are radio buttons to select whether the allocation method to use (for example, Item Allocation, Fixed Allocation, Fund Allocation), as well as a scissors icon with which you can delete the A/R selection.

 

 

Restrictions

 

Maximum Duration

Use the duration fields to control the span of time for which a program runs.  If this program type has no maximum or minimum duration, leave it blank.

For example, if this is a quarterly program, it should not run more than 90 days.  

To use these fields, select the checkbox and enter the number of days.

Minimum Duration

To ensure a minimum duration, as for a quarterly program, select the checkbox and enter the number of days.  For a quarterly program, you might enter 30.

Maximum Total Volume

If there is a maximum or minimum volume constraint on this program type, select the checkboxes and enter the volumes.

For example, if you know you shouldn't sell any more than 10,000 cases of something on promotion, indicate it here by selecting the checkmark for Maximum, and entering both the pounds and cases.

Minimum Total Volume

For example, if the promotion won't be lucrative unless it is for a minimum of 100 cases, select the checkbox for Minimum and enter both the pounds and cases.

Minimum Lump Sum

If you have a minimum lump sum, enter it in dollars. This amount applies to each individual lump sum.

For example, you might not want to do promotions with a lump sum of less than $100.00.  In that case, enter 10 in the dollars field.

Maximum Lump Sum

If there is a lump sum amount over which you would need special action (such as making a capital request), enter that figure here.  This amount applies to each individual lump sum.

For example, you might not be able to handle a promotion with a lump sum of greater than $10,000.  In that case, enter 10,000 in this field.

Lump Sum cap

If this program has a lump sum cap that you can pay out, enter it here.  If you have multiple lump sums on a program, this figure represents the combined lump sum amount that is the cap.

Program Date Type

Use the drop-down to select whether programs created with this template should require a fixed date type or allow free-form entry.

Last Date to Claim

Use this to control the date prior to which claims/billbacks will not be accepted.  You may not want to accept billbacks for a program that hasn't been active for some period of time.

For example, if you don't want billbacks accepted more than a year after the program ended, select the checkbox and enter 365 for the number of days.

Restrict on Level 4    

 

This field (the label verbiage may be different) refers to restricting template (and by inheritance, program) user permissions to a level of product hierarchy by product (type group, type code, or brand, whichever product entity you use for approval).

If you select the checkbox, an additional field displays beneath it with a [select] link so that you can indicate individual members of that hierarchical product level for access.  

Clicking the [select] link displays a pop-up window with all products at that level, each with a checkbox, and links to [import selected record(s)] [import all record(s)] [remove selected record(s)].     

Options

 

Select Products by Groups

Indicate whether this program type may allow selecting products by group rather than individually.  (If you do not select this checkbox, the Dynamic Groups checkbox beneath it is grayed out/disabled).

Dynamic Groups

(only applies to groups)

Provided you selected the checkbox to allow Select Products by Groups, this checkbox is available.

If you select Dynamic Groups, you are telling the system you want it to adjust the program membership and eligibility if membership changes during the program's duration.  

For example: If you have a program for a distributor ACME in which you offer a discount for all ACME houses, and after the program is in force, one ACME house goes out of business and ACME acquires two houses, the program eligibility has to be adjusted to drop the one house and make the other two eligible.

The dynamic group feature handles this.

Select Customers by Groups

Indicate whether this program type may allow selecting customers by group hierarchy rather than individually.

Click to see an example of the customers search by group window that displays for programs created with this template option.

Group Level Billback

Select this checkbox if programs created using this template type may allow billbacks by group level rather than individually.

Allow Add All Products

Select this checkbox if you want to enable the user to "add all" products rather than having to add each product individually.

Allow Retroactive Programs

Use this feature to permit users to enter programs after the date they were agreed to.

To allow retroactive entry of programs, select the checkbox and enter the number of days back that the program can be entered.  For example, you would not want programs to be created for a period for which the fiscal year had already been closed.

Allow Retroactive Revisions

This field is similar to the retroactive programs, except it pertains to program revisions.  For example, if you want to permit users to add products to a program, even if the program is active/in force, select this checkbox and enter the number of days back that they can revise it.

Allow Auto Renewal

If you want this program type to renew automatically, select this checkbox.

If you select automatic renewal for a program, the user who creates a program using this template sees an Auto Renewal checkbox.  If the user selects the Auto Renewal checkbox, the following additional auto renewal fields appear:

Days before start date to activate as ready for approval

Renew Annually, or Concurrently (after this one has completed)

Renew Concurrently means with no lapse, as for a program that runs the entire year.  For example, if you have a program that runs from August 1 to September 1 2005 (31 days), and you select Concurrent renewal, the renewal program will run from September 2 to October 3.

Renew Annually can be used for programs that repeat for a span of time (such as a program that pertains to the same three months every summer).  Using the program example above where the program runs from August 1 to September 1 2005, the annual renewal program would run from August 1 to September 1 2006.

An Auto Renewed program will automatically appear in the Ready for Approval box of the user in that position, according to the number of days before the calculated start date of the new program that were entered in the Days Before Start Date to Activate as Ready for Approval.

Allow Advanced Spending

Indicate whether this program type can include advanced spending. For example, if a program will require monies before its active date, select this checkbox.

If you select this checkbox, then programs created using this template will include the field "Advanced Spending Amount", and an area in which to enter the actual amount.

Allow Zero Volume

Indicate whether this program type can permit programs with no volume (zero volume).  If you leave this checkbox deselected, programs created using this template will require an entry for volume before permitting the program to be saved.

Controllable Volume

Indicate whether you want the users, such as sales people, to be able to control the volume.

If you select this checkbox, programs created using this template will include a field called Controllable with radio buttons for Yes or No.

Equipment and Dispenser Placement

Select this checkbox if this program type involves the provision and/or placement of equipment or dispenser (for example, a promotion for coffee might involve supplying and/or placing coffee-makers).

If you select this checkbox, programs created using this template will include this field with a checkbox to indicate whether equipment is involved.

Include in Catalog

Select this checkbox if you want this program type to be added in the catalog of read-only programs.  You might choose to exclude a particularly sensitive program from the catalog view, so that it would not be viewable even in "read-only" mode.

If so, indicate using the radio buttons whether it should be in the catalog in detail or summary form.

Include in Program Performance Report

If you want programs created using this template to be included in performance reports (such as may be found from the Home page, Tools, Reports), select this checkbox.

Check for Duplicate Programs  

Select this checkbox if you want the system to check for duplicate programs.  If you select this checkbox, two additional fields appear that allow you to tell the system how to handle duplicates:

Allow Duplicates of Approved Programs with a Warning

Prevent Duplicates of Approved Programs

If you select this checkbox, a program template page displays with additional options regarding program duplicates.

Payable To

Use the Payable To and Send Payment To fields to control who the check is made out to, and to whom it is sent.

Use the checkbox to include the Payable To information on the programs that are created using this template, and use the radio buttons to indicate whether Payable To is a required entry.

If you include Payable To information, then programs that are created using this template present payment options that permit the user to indicate who the check should made out to.

Send Payment To

Use the checkbox to include the Send Payment To information on the programs that are created using this template, and use the radio buttons to indicate whether Send Payment To is a required entry.  The Send Payment To may be different from the Payable To, so that you can make a check out to a broker and send it to the operator headquarters, for example.

Click to see an example of how the payable fields may appear on a program created using this template.

Customer Acceptance Block

Indicate using the checkbox whether programs created using this template should include a customer acceptance area.

 

 

Allowed access to profiles

The profiles sections allow you to control who has permissions to profiles.  The permissions you allow or forbid to this template are inherited by the programs created using this template.

Select the checkbox of the profiles who should be able to access this template and programs created with this template.

Allowed approval to profiles

Select the checkbox of the profiles who should be able to approve this template and programs created with this template.

Allowed lumpsum approval to profiles

Select the checkbox of the profiles who should be able to make lumpsum approvals to this template and programs created with this template.

Allowed billback approval to profiles

Select the checkbox of the profiles who should be able to make billback approvals to this template and programs created with this template.
