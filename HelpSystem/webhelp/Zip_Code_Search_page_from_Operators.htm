Postal Code search page from Operators

Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings Control Panel > Geography > Operators > postal codes tab > postal code search

URL Properties: search_screens/zipCode_Search.cfm

Select any combination of columns on which to search or just click the [search postal code] link to display all entries.

You can enter the City and County directly; use the dropdown arrows to select State, Sort By, Sort Order and Territory.  You can also key in a specific postal code and click [search] to see if it exists.

You can elect to list the postal codes that have already been assigned by selecting the "Show Assigned" checkbox.

To display only the postal code entries that have an operator assigned, select the "check for operator " checkbox.

Click the triangle next to "already selected postal codes" to display a listing in an expanded box.

When you click the [search market] link, the results display by Postal Code, City, County, State, Area Code, Time Zone and Market.

You can select the checkbox in the header row to include all postal codes, or, to include postal code rows selectively, click the checkbox next to the postal code row that you want to include, and then click the [import selected records] link.  You can use the [import] links to suit your needs provided they match your selection options: [import selected record(s)];  [import all record(s)];  [remove selected record(s)].  

The Postal Code Assign page redisplays showing the postal codes you selected.  Click any header row to sort your postal code results list by that row.

Click the scissors icon to the left of a row to mark it for removal from the selected list. When you click the scissors icon, the row is shown with a line through it to indicate it has been marked for removal, and the scissors icon changes to an "undo" arrow.  Click the undo icon to return the row to its selected status.

To actually assign a postal code to a market, click the [assign] link and a message displays indicating the postal code(s) and market that are now assigned.
