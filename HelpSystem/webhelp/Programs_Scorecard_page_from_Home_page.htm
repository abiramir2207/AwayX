Programs Scorecard page from Home page

Where can I find this in FORGESM?

Home > Program scorecard  

When you click on a program status (expired, pending approval, etc.) from the Home page Scorecard section, the Scorecard page for programs displays.

The Programs Scorecard page displays the listing of programs for the tab you selected (Work in Progress, Active, Expiring, etc.), with all other program lists by status available by simply clicking the other tabs.  

Remember that you can sort by any column header with blue text, and that you can control the sort order, by clicking the column title.  With adequate permissions (and provided it has not been approved), you can delete a program row using the scissors icon in the right-most column.  You can display the program listing by the number of total pages of programs using the page number links at the bottom, and you can display the programs by Program Type by clicking the alphabetical letter link corresponding to the first letter of the Program Type.

The status of the items displays in the left-most column: "hover" over any status, and an image pops up showing you the color coded statuses particular to the category you selected (Programs: Work in Progress, for example).  If you use the Catalog tab, which is a read-only presentation of programs, you may see multiple statuses.

If you see a lock icon next to the Status, it means another user has that program open.  If you "hover" over the lock icon, a pop-up message tells you who is using the program. If you click the program link for a locked program, you can view the program details but you cannot edit the program.   You may see a red triangle next to a program id: this means the program has been revised (if you hover over the triangle it will say "This is a Revision..."

You can "drill down" to display Program details by clicking the Program Id link.  If you see a black square to the immediate right of the program id, it means the program is a revised version of a previously approved program.

With appropriate permissions, you can use the links across the top right of the programs scorecard page to [search programs], [create new] programs, [approve] selected programs, and [print the results].  

Print results prints the page(s) of program listings as you see it on the screen.  Note that if you have 125 Expired Programs and you click Print Results, all 125 expired programs are listed on the printout (which may require 5 pages).  If you print a larger number of items, be aware that it will require a corresponding number of printer pages.
