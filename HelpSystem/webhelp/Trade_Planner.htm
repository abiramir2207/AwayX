Where can I find this in FORGESM?

Home > Programs > Trade Planner

Use the Trade Planner to see the impact that a discount will have, without creating an entire program.  The Trade Planner allows you to see the final margin with the discount, and you can change the rate and volume to make instant projections.  

Initially, the existing list of trade planning entries displays, showing the following for eadh entry: Trade Plan Title, Date Created, Created By, Date Last Updated, and Updated By.  

Use the [create] link to make a new trade planner entry, or click the [display] link next to an existing trade planning entry to display details about the entry.

Trade Planner Click the [edit] link to change an existing planning record and make a new projection; click the [delete] link to delete this planning record.  Click [create WIP] to put this trade planning record in your WIP folder.

Trade spending planner page

Report Title - Enter a name for this trade planning record.

Notes - Enter descriptive information that describes this projection.

Customer - Click [select distributor] to display the Select Distributors/customer search page.  Select the radio button next to the customer you want to include in the trade planning projection, and the trade planning page displays showing your customer selection.

Span - Select the From and To dates for this projection using the calendar.

Products - Click the [select products] link to find the products to include.  Select the checkbox(es) of the products you want to include, and click the [import selected products] link.  The trade planning page displays showing the products you selected, with an additional link to select [volume].  Additional sections display below the products section for Costs and Profit Analysis.

Click the [display] link next to a trade planning row to display the details:

Header columns include Report Title, Created By/on, Notes, Customer (Distributor) and Span (dates).

Body information for Products - displayed and not editable - includes Item, Description, Case Cost (the amount it costs to produce this product), Case Net Wgt. (the weight of the product per case in pounds), Case List Price.

Body information for Products -  editable -

Proposed Case List Price (enter the case price you want to use for this product)

Quantity/Case (enter the amount of the product you want to use in this projection)

Body information for Products - calculated -

Volume (lbs) - based on the Quantity/Case you entered above

Total Cost (Case Cost * Quantity)

Revenue (Proposed Case List Price * Quantity/Case)

Mix % Revenue -This is the percentage of revenue that the product is responsible for.  For example, if there are three items, and they earn $200, $300 and $500, the mix percentage would be 20%, 30% and 50%.

Mix % Wgt. - This is the percentage of total weight that the product is responsible for (similar to the revenue mix, but for weight).

Extended Margin %, and Extended Margin $ - These values show you the percent and dollars of marine that will be generated by your proposed case list price.

Costs information - Use this section to enter Costs that will affect the margin for the trade plan you are projecting.  

Program Incentive Costs - Use the drop-down to select the rebate component to use, enter a value and then select whether the value is a percentage or dollar value.  Use the plus button to add multiple incentive costs.  Use the minus button next to an incentive cost row to remove it.

Select the checkbox next to an incentive to include it for this product.

Miscellaneous Costs - Enter miscellaneous costs (such as spoilage, brokerage, cash discounts) that are not related to incentive costs.  Enter a descriptive name, enter the value and select percent or dollar.

Select the checkbox next to the cost to include it for this product.  When you click the [calculate] link (next to Profitability Analysis), your entries are calculated and the results shown.

Lump Sum Costs - Select the lump sum cost type using the drop-down, and enter the value to use.  As with the other costs, use the plus buttons to add multiple lump sum costs, and use the minus button to remove them.  Click the [calculate] link to see the results.

Profitability Analysis - The calculated costs are shown, broken out by program incentive, miscellaneous and lump sum.  The Total Net Margin for all items in the program is shown, and the Total Net Profit shows the total dollar profit from all products in the trade plan.

The Totals are enclosed by a green box if the plan is profitable, and by a red box if the plan is not profitable.

[Create WIP] - Click this link when you are ready to create a WIP in your folder based on this program. The Select Program Type page displays so that you can select the template to use for this trade program.  When you select the program template type to use, it displays the basic info page with some of the program information automatically filled in from the trade planner.
