List Users - from Settings, Users

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Settings Control Panel > Users > list users

URL Properties: settings/Access_Rights/users_search_form.cfm?PageTitle=Users: list users

List users displays a full listing of all users in your system.  

To locate a specific user, click the letter next to "last names starting with" that corresponds to the first letter of their last name.  

Click the column header of any of the following to sort by the field, and click again to reverse the sort order: First Name, Last Name, Profile and Position can be used as sort columns.  Note that if you click the Last Name column to sort, the list is sorted by last name but the order of the names (first, then last) does not change.

To display the detail page for a user, click any of the listed fields and the edit user page displays (provided you have permissions).  You can change selections for this user, and, with adequate permissions, you can also reset the password for the user from the edit user page.

Back on the list users page, you can delete a user by clicking the "x" in the right column next to the user row.  If you click the "x" to delete a user, a message displays explaining that if you delete a user, the user will no longer have access to the FORGESM application.
