Select Program Territory

 Blacksmith Applications, www.blacksmithapps.com

Where can I find this in FORGESM?

Home > Programs (click a program link) > click territory

The select program territory page is similar to the select program customers page.

The territory search fields let you search for all in each category, or search for selected members of each category.  (click to see an image of a territory search page).

Division

Region

Line of Business

Status

 

In addition to using drop-downs to select from the fields above, you can enter and search by Name.

Select the search field on which to sort your search results using the Sort By drop-down, and select ascending or descending order using the Order drop-down.

To clear any search criteria, click the [reset] link in the lower right.

To execute your search, click the [search territory] link.

Click the [get territory by program] link to display a program-based search page.  The program-based search page is the same page that displays from the program scorecard.

When you click save, the next program page displays: Product Rebate Entry.
