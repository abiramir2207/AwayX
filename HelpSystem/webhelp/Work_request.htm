How to create the perfect work request ?

 Blacksmith Applications, www.blacksmithapps.com

To ensure that Work Requests are processed accurately and promptly, please use the below model.  It provides an explanation of each field and examples of information needed.

Explanation:

Issue Title

     A description of the issue/request. 

Examples:  a) Program 1001000 not routing correctly.  b)  Resend 900 interface  c) Vantage query not returning results

 

URL of the environment

     URL of the environment related to the issue/request. 

             Example:  acme@awayx.com, acme.stage@awayx.com

 

Prog ID, BB ID, DD ID, Interface Name

Program #, Billback #, Deduction # and/or Interface name that corresponds to the issue/request.  Examples:  a) Prog 1001000 & Billback 1231945-00  b) 900 interface  c) Vantage RFA report

 

User Name/Password/Position/Profile

Provide the user name and any additional info about the user such as their profile and/or position.  Example:  jdoe1 / broker profile / broker boston position

 

Error Event #

     If an error event occurred, provide the event #. 

     Example:  error event # 368

 

What is current behavior

     Describe the issue/request in detail that includes the clicks the user took. 

     Examples:  a) User created program.  The user submitted the program for approval by clicking on ‘click here to approve the program’.  User could only agree to the program.  The program appears correctly in the user’s agreed status.  It is not routing to the Region Manager, John Doe.   b)  Resend 900 interface from 1/5/2010 for billback # 104322-00.  c) Vantage RFA report is missing programs.  Program 1023345 is RFA within FORGE but not on vantage report.

 

What is expected behavior

     Describe how the issue/request should work. 

     Examples:  a) the program should now route to Region Manager, John Doe, and be in their RFA status.  b)  Please put on the FTP folder, a copy of the 900 interface.  c)  Vantage RFA report to show programs which are RFA within FORGE, specifically program 1023345.

 

Reference #

     If your company has its own reference or tracking number, enter the number that relates to this issue/request.

 

Priority

     Select your prioritization of this issue/request

 

What part of the application is affected

     Select the part of the application that the issue/request relates to.

 

What kind of request is this

Select whether this is a defect, enhancement or inquiry.

·     Defect:  an issue or bug with how the code is working

·     Enhancement:  a change request.  Wanting the application to behave in a different manner. 

·     Inquiry:  request to know how a feature works; explanation of current logic
