saveAlerter()method 
public function saveAlerter(xx:*, strTitle:String, doAction:String):void

This function is used in the MainEventMap to show alerts after saving the data. This alert will be shown for 2.5 seconds and automatically close after than and User will not have an option to click "OK" button as no button will be displayed in this alert.

Parameters

xx:* — This could be of any type hence (xx: is set as the type for the param
 
strTitle:String — This param holds the title that needs to be displayed for the Alert
 
doAction:String — This param will be checked and only if it is "doSave" the Alert will be displayed
