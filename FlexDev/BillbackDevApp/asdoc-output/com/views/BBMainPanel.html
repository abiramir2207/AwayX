fnDoActions()method 
public function fnDoActions(e:Event):void

This function takes the Event parameter and assigns the strAction variable accordingly and based on the strAction does an approval and takes the user to a different page or saves and runs the deviation. strAction: This variable holds the value "doSaveApprove" or "doSaveRecalc" so if the value is "doSaveApprove" then the page is saved and then redirected to the Approve cfm page. If the value is "doSaveRecalc" then the page is saved and Deviation is run.

Parameters

e:Event — This param holds the event that called this function
