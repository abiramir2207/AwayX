pqSelect is a standalone jQueryUI widget which turns browsers' native single and multiple select lists into easy to use drop downs embellished with checkboxes, search box, keyboard navigation and rich set of options, methods and events. It works in all major browsers (IE8+, Chrome, Firefox, Safari, Opera) and across desktops, tablets and touch devices. It also supports grouping and disabled options. Please check here for demos.
Options
bootstrapType: Object
Default: { on: false, btn: 'btn btn-default', popupCont: 'panel panel-default', selectCls: 'label label-info', itemCls: 'label label-default', closeIcon: 'glyphicon glyphicon-remove', searchIcon: 'glyphicon glyphicon-search' }

This option injects bootstrap specific classes in the component.

Code examples:

Initialize the pqSelect with bootstrap option specified.

?
1
2
//turn on bootstrap support in pqSelect.
$( ".selector" ).pqSelect( { bootstrap: { on: true } } } );

Get or set the bootstrap option, after initialization:

?
1
2
3
4
5
//getter
var bootstrap = $( ".selector" ).pqSelect( "option", "bootstrap" );
 
//setter
$( ".selector" ).pqSelect( "option", "bootstrap", { on: true } );

              refresh()

              Refreshes the view of pqSelect. It's useful to refresh view after change in option/options.

              • This method does not accept any arguments.

              Code examples:

              Invoke the method:

              ?
              1
              $( ".selector" ).pqSelect( "refresh" );

              refreshData()

              Reloads the data from select list and refreshes the view of pqSelect. It's useful to refresh view after change in options of underlying select list.

              • This method does not accept any arguments.

              Code examples:

              Invoke the method:

              ?
              1
              $( ".selector" ).pqSelect( "refreshData" );
